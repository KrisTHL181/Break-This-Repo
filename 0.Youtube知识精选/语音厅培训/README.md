# 语音厅培训

> **来源概述**：语音厅行业的聊天话术培训资料（来源：用户的语音厅同事）。**不是某位讲师**，而是一套行业内部流传的课件——面向**女性**（尤其语音厅女主持），教如何用话术让男性对象为女性投入金钱、情绪与陪伴。原始资料编号 02-07，缺 01、05。

**性质提示**：这套内容与知识库中其他作者（松明老师、江寒在此）有本质区别——后者讲"健康关系"，这套讲**话术与操控**。其价值有两层：①**进攻层**——了解"记忆感/仪式感/共鸣感/参与感/特别感"等机制可正向用于任何关系；②**防御层**——认识话术的工业化生产流程，以便识别他人是否在对自己使用。
