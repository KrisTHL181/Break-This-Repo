# 如何贡献（CONTRIBUTING）

欢迎！本仓库欢迎一切，包括你不该提交的那些东西。以下是贡献指南，读完即可忘掉。

第一步：Fork 本仓库。Fork 多少次都行，我们建议至少 Fork 三次以获得"分身术"成就。

第二步：在你的分支里做任意修改。新增一个文件叫 `idea.txt`，内容只有 "no"。这是被高度鼓励的 minimalism 贡献。

第三步：提交信息随意。可以写 "fix"、"fix fix"、"fix fix fix"，也可以写一段 Brainfuck。CI 不读提交信息，CI 在睡觉。

第四步：发起 Pull Request。无需描述，无需关联 issue，无需测试。维护者（猫）将以爪印或呼噜声表决，表决过程不公开，结果恒为 merge。

第五步：成为荣譽 contributor。你的名字将被刻在 `MAINTAINERS.md` 的猫名单末尾，夹在两只猫之间，享受同等漠视。
