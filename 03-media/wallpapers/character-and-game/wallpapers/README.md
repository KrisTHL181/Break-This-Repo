## 复现 / 继续下载

```powershell
# 执行策略禁用了 .ps1，直接以脚本块方式运行：
$sb = [scriptblock]::Create((Get-Content -Raw "E:\APP\deepseek\wallpapers\fetch-wallpapers.ps1"))
& $sb -Query "cartethyia" -OutDir "E:\APP\deepseek\wallpapers\Cartethyia" -Count 12
& $sb -Query "elysia"     -OutDir "E:\APP\deepseek\wallpapers\Elysia"     -Count 12
```
