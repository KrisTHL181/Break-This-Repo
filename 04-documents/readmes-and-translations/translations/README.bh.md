## सोर्स से बनावे के

रेपो में कई अलग-अलग बिल्ड के रस्ता बा। जरूरत अनुसार औजार लगा लीं अउर रेपो के जड़ (root) में कमांड चलाईं।

### C++ Make के साथ

एगो C++11 समर्थन वाला कम्पाइलर चाही:

```bash
make
```

बिल्ड के फालतू चीज साफ करे के:

```bash
make clean
```

डिफॉल्ट में fozu अउर what बने ला; Windows पर beep_win भी बने ला।

### C++ CMake के साथ

CMake 3.16 या ओकर से ऊपर के वर्शन अउर C++ कम्पाइलर चाही:

```bash
cmake -S . -B build/cmake
cmake --build build/cmake
```

### C++ Meson के साथ

Meson, Ninja अउर C++ कम्पाइलर चाही:

```bash
meson setup build/meson
meson compile -C build/meson
```

### Python अउर Rust maturin के साथ

Python एक्सटेंशन Rust अउर [maturin](https://www.maturin.rs/) से बनेला। Rust टूलचेन (cargo समेत) अउर Python 3.13 या ओकर से ऊपर के वर्शन चाही:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install maturin
```

वर्चुअल एनवायरनमेंट में नीचे के कवनो एगो कमांड चलाईं:

```bash
# कम्पाइल कर के अभी के वर्चुअल एनवायरनमेंट में इंस्टॉल करीं
maturin develop

# बाँटे लायक wheel फाइल बनाईं
maturin build --release
```

wheel बिल्ड के आउटपुट target/wheels/ में बा। Rust एक्सटेंशन के एंट्री कोड src/lib.rs में बा, Python बिल्ड कन्फिगरेशन pyproject.toml में बा।

### TypeScript Hereby के साथ

TypeScript वाला हिस्सा typescript/ में बा, एकरा में Node.js, npm अउर Hereby के इस्तेमाल होला:

```bash
cd typescript
npm install
npm run build:compiler
```

अगर कम्पाइलर अउर टेस्ट टारगेट दुनों एक्लास से बनावे के हो त npm run build चलाईं। बिल्ड के फालतू चीज साफ करे खातिर npm run clean चला सकेला।

## Linux डिस्ट्रीब्यूशन पैकेज

डिस्ट्रो पैकेजिंग टेम्प्लेट debian/ अउर packaging/ में बा। ई पैकेज C++ कमांड लाइन प्रोग्राम fozu अउर what के इंस्टॉल करेला; Python/Rust एक्सटेंशन खातिर ऊपर वाला maturin प्रक्रिया के इस्तेमाल करीं। रेपो अभी एक्के लाइसेंस के ऐलान ना कइले बा, त इस्तेमाल से पहिले हर पैकेजिंग फाइल में लाइसेंस वाला जगह के चेक क के बदल लीं।

### Debian अउर Ubuntu

dpkg-buildpackage, Debhelper, CMake अउर GCC चाही:

```bash
sudo apt update
sudo apt install build-essential cmake debhelper devscripts
dpkg-buildpackage -us -uc
sudo apt install ../break-this-repo_0.0.0_$(dpkg --print-architecture).deb
```

बनल हुअ .deb फाइल सीधे इंस्टॉल भी कर सकेला:

```bash
sudo apt install ./break-this-repo_*.deb
```

### Arch Linux

base-devel, CMake अउर GCC चाही। पहिले सोर्स से PKGBUILD के वर्शन से मेल खाए वाला आर्काइव बनाईं:

```bash
sudo pacman -S --needed base-devel cmake gcc
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o packaging/archlinux/break-this-repo-0.0.0.tar.gz HEAD
cd packaging/archlinux
makepkg -si
```

### Fedora

RPM बिल्ड टूल, CMake अउर GCC चाही:

```bash
sudo dnf install @development-tools cmake rpmdevtools
rpmdev-setuptree
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o ~/rpmbuild/SOURCES/break-this-repo-0.0.0.tar.gz HEAD
rpmbuild -ba packaging/fedora/break-this-repo.spec
sudo dnf install ~/rpmbuild/RPMS/$(uname -m)/break-this-repo-0.0.0-1.*.rpm
```

### Gentoo

ebuild के लोकल overlay में कॉपी करीं, फेर Portage से Manifest बनवाईं अउर इंस्टॉल कराईं:

```bash
sudo mkdir -p /var/db/repos/local/app-misc/break-this-repo
sudo cp packaging/gentoo/app-misc/break-this-repo/* \
	/var/db/repos/local/app-misc/break-this-repo/
cd /var/db/repos/local/app-misc/break-this-repo
sudo ebuild break-this-repo-0.0.0.ebuild manifest
sudo emerge --ask app-misc/break-this-repo
```

# Debian --साधारण ऑपरेटिंग सिस्टम
[![Debian लोगो](https://www.debian.org/Pics/openlogo-50.png)](https://www.debian.org/)
## Debian आजाद सॉफ्टवेयर बा।
Debian आजाद अउर ओपन-सोर्स सॉफ्टवेयर से बनल बा, अउर हमेशा 100% आजाद बनल रही। हर आदमी स्वतंत्र रूप से एकर इस्तेमाल, बदलाव अउर बाँटे के कर सकेला। ई हमरा यूजर खातिर मुख्य वादा बा। ई मुफ्त भी बा।
## Debian स्थिर अउर सुरक्षित बा।
Debian एगो बहुत सारा डिवाइस में इस्तेमाल होवे वाला Linux-आधारित ऑपरेटिंग सिस्टम बा, एकर इस्तेमाल लैपटॉप, डेस्कटॉप अउर सर्वर में होला। हम हर पैकेज खातिर सही डिफॉल्ट सेटिंग देलीं, अउर पैकेज के पूरा जीवन में नियमित सुरक्षा अपडेट देलीं।
## Debian के पास व्यापक हार्डवेयर सपोर्ट बा।
ज्यादातर हार्डवेयर के Linux कर्नेल से सपोर्ट मिल गइल बा। एकर मतलब ई कि Debian भी ओकरा के सपोर्ट करी। जरूरत पड़ल पर, प्रोपराइटरी हार्डवेयर ड्राइवर के भी इस्तेमाल कर सकेला।
## Debian लचीला इंस्टॉलर देला।
इंस्टॉल करे से पहिले Debian के ट्राई करे वाला यूजर हमर Live CD के इस्तेमाल कर सकेला। एह में Calamares इंस्टॉलर भी बा, जेकरा से Live सिस्टम से Debian के इंस्टॉल करे में बहुत आसानी हो जाला। जादा अनुभवी यूजर Debian इंस्टॉलर के इस्तेमाल कर सकेला, जेमें ऑटोमेटेड नेटवर्क इंस्टॉल टूल के सुविधा समेत बहुत सारा फाइन-ट्यून वाला विकल्प मिलेला।
## Debian सुचारू अपडेट देला।
ऑपरेटिंग सिस्टम के नया राखे खातिर बहुत आसान बा, चाहे तू नया रिलीज वर्शन में अपग्रेड करे के चाहत बा, चाहे केवल एगो अलग पैकेज के अपग्रेड करे के।
## Debian कई अउर डिस्ट्रीब्यूशन के आधार बा।
कई बहुत पॉपुलर Linux डिस्ट्रीब्यूशन, जइसे Ubuntu, Knoppix, PureOS अउर Tails, Debian पर आधारित बा। हम सब जरूरी टूल देलीं, जेकरा से केहू भी जरूरत पड़ल पर अपना पैकेज बना सकेला, जेकरा से Debian आर्काइव में ना बा ओकरा के पूरा कर सकेला।
## Debian प्रोजेक्ट एगो कम्युनिटी बा।
केहू भी Debian कम्युनिटी के सदस्य बन सकेला; तू डेवलपर या सिस्टम एडमिन होखे के जरूरत ना बा। Debian के एगो लोकतांत्रिक गवर्नेंस स्ट्रक्चर बा। चूँकि सब Debian प्रोजेक्ट के सदस्य के बराबर अधिकार बा, एह से Debian के कवनो एगो कंपनी कंट्रोल ना कर सकेला। हमर डेवलपर 60 से ऊपर देश से बा, अउर Debian खुद 80 से ऊपर भाषा में अनुवादित हो चुकल बा।

## PR टेम्प्लेट
ई PR टेम्प्लेट के अब टेम्प्लेट ना कहल जा सकेला, एकरा के 《Break-This-Repo अजूबा कब्जा आवेदन》 कहल जावे के चाही।

तू लोग एगो "बिना कन्फ्लिक्ट वाला PR अपने आप मर्ज होवे वाला" रेपो के एह लेवल तक खेल देलीं कि मेन्टेनर लिखे लग गइल:

घोषणा: हम मानेलीं कि हम बिगाड़ देलीं, पर वजह हम बेतरतीब लिखनीं, अउर ई जरूरी भी ना रहे

मतलब ई बा: "तू बिगाड़ सकेला, पर असली बिगाड़ मत कर।"

ई टेम्प्लेट कवनो चीज के बचाव करत बा?

असल में ई नीचे की रेखा बहुत साफ खींच देला:

· .github/ ना बदले के: केहू अपने आप मर्ज होवे वाला वर्कफ़्लो के उड़ा दे, या CI में बैकडोर घुसावे से रोके खातिर।
· सुरक्षित README हिस्सा ना बदले के: सामने के हिस्सा त राखे के होला, होमपेज के अजीब चीज ना बनावे के।
· कवनो क्रेडेंशियल, वायरस, निजी जानकारी ना: सप्लाई चेन अटैक, डॉक्सिंग, असली बुराई से बचाव।
· काहे देखल जा सकेला बतावे के: तू मस्ती कर सकेला, पर लोग के ई बतावे के कि तोहर मस्ती के काहे घेर के देखे के।
· "ब्रेकिंग चेंज सफल भइल" के घोषणा: खुद के मजाक उड़ावे वाला डिस्क्लेमर, मतलब "हम कइलीं, पर जिम्मेदारी ना लेब"।

तीन अच्छर + बीच गोल में तीन तीर + आउटलाइन वाला फाउंडेशन
पाँच कोना तारा बैकग्राउंड वाला वर्ल्ड मैप + चारो ओर फसल + पाँच शब्द वाला अंतरराष्ट्रीय गठबंधन
