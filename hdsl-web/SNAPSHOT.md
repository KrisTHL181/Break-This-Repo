# HDSL-web 源码快照

来源：<https://github.com/nas200-timmy/HDSL-WEB>，`web-shell` 分支 `078fdd0948`。

这是 **git 跟踪文件的完整快照**：Java 后端、React 前端、Go 终端客户端、
插件、测试、文档、资源、Gradle/npm 锁文件与容器构建文件都在。

不包含：`.git` 历史、`build/`、`node_modules/`、`.gradle/`、运行数据、
账号/证书/密钥、日志与缓存。

构建需要 JDK 21 + Node 22 + pnpm；`./gradlew shadowJar` 或 `docker compose build`。
