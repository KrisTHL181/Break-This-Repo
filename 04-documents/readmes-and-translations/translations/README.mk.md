## Изградба од изворниот код

Репозиторито содржи неколку независни влезни точки за изградба. Инсталирај ги потребните алатки и изврши ги командите од коренот на репозиторито.

### C++ со Make

Ти треба компајлер што поддржува C++11:

```bash
make
```

За чистење на артефактите од изградбата:

```bash
make clean
```

Стандардно се создаваат `fozu` и `what`; на Windows и `beep_win`.

### C++ со CMake

Ти треба CMake 3.16 или понов, и компајлер за C++:

```bash
cmake -S . -B build/cmake
cmake --build build/cmake
```

### C++ со Meson

Ти требаат Meson, Ninja и компајлер за C++:

```bash
meson setup build/meson
meson compile -C build/meson
```

### Python и Rust со maturin

Python екстензијата се изградува со Rust и [maturin](https://www.maturin.rs/). Ти треба Rust-алатна верига (со `cargo`) и Python 3.13 или понов:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install maturin
```

Во виртуелното опкружување изврши една од овие команди:

```bash
# Компајлирај и инсталирај во тековното виртуелно опкружување
maturin develop

# Изгради дистрибуирачка wheel-датотека
maturin build --release
```

Wheel-овите се создаваат во `target/wheels/`. Влезниот код на Rust-екстензијата е во [`src/lib.rs`](src/lib.rs), а конфигурацијата за изградба на Python во [`pyproject.toml`](pyproject.toml).

### TypeScript со Hereby

Делот TypeScript се наоѓа во `typescript/` и користи Node.js, npm и Hereby:

```bash
cd typescript
npm install
npm run build:compiler
```

Ако сакаш да ги изградиш и компајлерот и тест-целите, изврши `npm run build`. За чистење на артефактите од изградбата можеш да извршиш `npm run clean`.

## Важен додаток

При компајлирање обезбеди барем 114GB меморија и не помалку од 514GB простор за складирање; потребно е да користиш CPU со 1919810 јадра на 10GHz

## Пакувања за Linux дистрибуции

Шаблоните за пакување за дистрибуции се во `debian/` и `packaging/`. Овие пакувања ги инсталираат C++ програмите за командна линија `fozu` и `what`; за Python/Rust-екстензијата сè уште користи ја maturin постапката погоре. Репозиторито сè уште не декларира обединета лиценца за отворен код, па пред официјално издавање провери и замени го полето за лиценца во секоја датотека за пакување.

### Debian и Ubuntu

Ти требаат `dpkg-buildpackage`, Debhelper, CMake и GCC:

```bash
sudo apt update
sudo apt install build-essential cmake debhelper devscripts
dpkg-buildpackage -us -uc
sudo apt install ../break-this-repo_0.0.0_$(dpkg --print-architecture).deb
```

Можеш и директно да инсталираш веќе изградена `.deb` датотека:

```bash
sudo apt install ./break-this-repo_*.deb
```

### Arch Linux

Ти требаат `base-devel`, CMake и GCC. Прво генерирај од изворниот код архив што одговара на верзијата во `PKGBUILD`:

```bash
sudo pacman -S --needed base-devel cmake gcc
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o packaging/archlinux/break-this-repo-0.0.0.tar.gz HEAD
cd packaging/archlinux
makepkg -si
```

### Fedora

Ти требаат алатки за изградба на RPM, CMake и GCC:

```bash
sudo dnf install @development-tools cmake rpmdevtools
rpmdev-setuptree
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o ~/rpmbuild/SOURCES/break-this-repo-0.0.0.tar.gz HEAD
rpmbuild -ba packaging/fedora/break-this-repo.spec
sudo dnf install ~/rpmbuild/RPMS/$(uname -m)/break-this-repo-0.0.0-1.*.rpm
```

### Gentoo

Копирај го ebuild во локален overlay и потоа остави Portage да генерира Manifest и да инсталира:

```bash
sudo mkdir -p /var/db/repos/local/app-misc/break-this-repo
sudo cp packaging/gentoo/app-misc/break-this-repo/* \
	/var/db/repos/local/app-misc/break-this-repo/
cd /var/db/repos/local/app-misc/break-this-repo
sudo ebuild break-this-repo-0.0.0.ebuild manifest
sudo emerge --ask app-misc/break-this-repo
```

# Debian --општ оперативен систем
[![Debian Logo](https://www.debian.org/Pics/openlogo-50.png)](https://www.debian.org/)
## Debian е слободен софтвер.
Debian е составен од слободен софтвер со отворен код и секогаш ќе остане 100 % слободен. Секој е слободен да го користи, менува и дистрибуира. Ова е нашата главна заложба кон нашите корисници. Исто така е бесплатен.
## Debian е стабилен и безбеден.
Debian е оперативен систем заснован на Linux, кој се користи на секакви уреди, од преносни сметачи до стони сметачи и сервери. Нудиме разумни стандардни конфигурации за секое пакување и редовни безбедносни ажурирања во текот на целиот животен циклус на пакувањето.
## Debian има широка поддршка за хардвер.
Поголемиот дел од хардверот веќе е поддржан од Linux јадрото. Тоа значи дека и Debian го поддржува. Доколку е потребно, може да се користат и сопственички хардверски драјвери.
## Debian нуди флексибилен инсталатер.
Корисниците што сакаат да го пробаат Debian пред да го инсталираат можат да го користат нашиот Live CD. Тој го вклучува и инсталатерот Calamares, што ја прави инсталацијата на Debian од жив систем многу лесна. Поискусните корисници можат да го користат инсталатерот на Debian, кој нуди повеќе можности за фино подесување, вклучително и можноста да се користат алатки за автоматска мрежна инсталација.
## Debian нуди непречено ажурирање.
Одржувањето на оперативниот систем ажуриран е многу лесно, било да сакаш да се надградиш на сосема нова верзија или само да ажурираш едно пакување.
## Debian е основа на многу други дистрибуции.
Многу многу популарни Linux дистрибуции, како Ubuntu, Knoppix, PureOS и Tails, се засноваат на Debian. Ги нудиме сите потребни алатки за секој да може да изработи свои пакувања кога му се потребни, за да ги дополни оние што не се во архивата на Debian.
## Проектот Debian е заедница.
Секој може да биде дел од заедницата на Debian; не мора да бидеш развивач или системски администратор. Debian има демократска структура на управување. Бидејќи сите членови на проектот Debian имаат еднакви права, Debian не може да биде контролиран од една компанија. Нашите развивачи доаѓаат од повеќе од 60 земји/региони, а самиот Debian е преведен на повеќе од 80 јазици.

## Шаблон за PR
Овој шаблон за PR веќе не може вистински да се нарече шаблон; треба да се вика «Барање за задржување на аномалија за Break-This-Repo».

Вие зедовте репозитори што само «автоматски спојува PR без конфликти» и игравте со него толку долго што одржувачот почна да пишува:

Тип: клоца во README / клоца во документација / дефект на код на празен град / инцидент предизвикан од мачка / натприродна појава
Верификација: не го чепнав .github/, не го чепнав заштитениот README, нема вируси, нема лични податоци
Изјава: признавам дека го скршив, но причината ја измислив, и воопшто не е задолжителна

Во суштина тоа значи: «можеш да правиш неред, но не вистински неред».

Од што штити овој шаблон?

Всушност ја повлекува границата многу јасно:

· Не чепкај .github/: спречува некој да го разнесе самиот тек на автоматско спојување или да стави задни врати во CI.
· Не чепкај ги заштитените делови на README: фасадата сè уште е потребна, не можеш почетната страница да ја направиш нешто чудно.
· Нема акредитиви, вируси или лични податоци: против напади на синџирот на снабдување, против доксинг, против вистинска злонамерност.
· Објасни како да се набљудува: можеш да направиш трик, но луѓето мора да знаат како да го гледаат.
· Изјави «успешен breaking change»: самоиронично отфрлање на одговорност, односно «го направив тоа, но не сум одговорен».

Што се однесува до серијата «натприродна појава»:

три букви + три стрелки околу круг + фондација со контура
светска карта на позадина од пентаграм + околу прстен од посеви + меѓународен сојуз од пет збора

Првата е Фондацијата SCP; втората е веројатно меѓународна организација како FAO / Организацијата за храна и земјоделство на ОН. Преведено, тоа значи:
«Ова веќе не е проблем со кодот; препорачуваме да ја пријавиш аномалијата на организација за задржување на аномалии.»

Како твојот commit може да се вклопи во овој шаблон?

Ги качуваш изворните кодови на Minecraft, OpenJDK и Fabric Loader, во 4 commit-а собираш над 12,7 милиони линии; како тип можеш да означиш:

☑ клоца во документацијата

## Археолошки архив на инфраструктурата на самото место

![EGIEM-R1, вистинскиот прототип: фотографија од местото](./Emergency-Generator-Interface-Elevation-Module/assets/rock-field-photo.png)

Ова репозитори сега чува дел од инфраструктура на самото место со мала потрошувачка, висока доверливост и целосно офлајн: камен што беше привремено повикан во критичен момент. Нема процесор, нема мрежна карта и нема намера да даде отказ; само со сопствената тежина цврсто ја држи кутијата за интерфејс на вистинското место.

Жолтата етикета е тоа што го подига «најдов камен» на «запишан во регистарот на опрема». По прелиминарна проценка, овој уред не бара ни најава, ни ажурирања, ни рестартирања; единствената позната операција за одржување е: не го чепкај.

Зависност нагоре: кутија за интерфејс на генераторот на операторот  
Зависност надолу: Земјата  
Работен статус: работи стабилно

Фотографијата е оригиналната слика од местото што ја даде придонесувачот; нормализирано е само името на датотеката, без отсекување и прецртување.
