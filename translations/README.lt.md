## Kompiliavimas iš šaltinio kodo

Saugykloje yra keli nepriklausomi kompiliavimo įėjimo taškai. Įdiek reikiamus įrankius ir vykdyk komandas iš saugyklos šaknies.

### C++ su Make

Reikia kompiliatoriaus, palaikančio C++11:

```bash
make
```

Norėdamas išvalyti kompiliavimo artefaktus:

```bash
make clean
```

Pagal nutylėjimą sukuriami `fozu` ir `what`; „Windows“ dar ir `beep_win`.

### C++ su CMake

Reikia CMake 3.16 ar naujesnio ir C++ kompiliatoriaus:

```bash
cmake -S . -B build/cmake
cmake --build build/cmake
```

### C++ su Meson

Reikia Meson, Ninja ir C++ kompiliatoriaus:

```bash
meson setup build/meson
meson compile -C build/meson
```

### Python ir Rust su maturin

Python plėtinys kompiliuojamas su Rust ir [maturin](https://www.maturin.rs/). Reikia Rust įrankių grandinės (su `cargo`) ir Python 3.13 ar naujesnio:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install maturin
```

Virtualioje aplinkoje vykdyk vieną iš šių komandų:

```bash
# Kompiliuoti ir įdiegti į dabartinę virtualią aplinką
maturin develop

# Sukurti platinamą wheel failą
maturin build --release
```

Wheel failai sukuriami `target/wheels/`. Rust plėtinio įėjimo kodas yra [`src/lib.rs`](src/lib.rs), o Python kompiliavimo konfigūracija — [`pyproject.toml`](pyproject.toml).

### TypeScript su Hereby

TypeScript dalis yra `typescript/` ir naudoja Node.js, npm ir Hereby:

```bash
cd typescript
npm install
npm run build:compiler
```

Jei nori kompiliuoti ir kompiliatorių, ir testavimo tikslus, vykdyk `npm run build`. Norėdamas išvalyti kompiliavimo artefaktus, gali vykdyti `npm run clean`.

## Paketai Linux distribucijoms

Distribucijų pakavimo šablonai yra `debian/` ir `packaging/`. Šie paketai įdiegia C++ komandinės eilutės programas `fozu` ir `what`; Python/Rust plėtiniui vis dar naudok aukščiau aprašytą maturin procesą. Saugykla dar nedeklaruoja vieningos atvirojo kodo licencijos, todėl prieš oficialų leidimą patikrink ir pakeisk licencijos lauką kiekviename pakavimo faile.

### Debian ir Ubuntu

Reikia `dpkg-buildpackage`, Debhelper, CMake ir GCC:

```bash
sudo apt update
sudo apt install build-essential cmake debhelper devscripts
dpkg-buildpackage -us -uc
sudo apt install ../break-this-repo_0.0.0_$(dpkg --print-architecture).deb
```

Taip pat gali tiesiogiai įdiegti jau sukompiliuotą `.deb` failą:

```bash
sudo apt install ./break-this-repo_*.deb
```

### Arch Linux

Reikia `base-devel`, CMake ir GCC. Pirmiausia sukurk iš šaltinio kodo archyvą, atitinkantį `PKGBUILD` versiją:

```bash
sudo pacman -S --needed base-devel cmake gcc
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o packaging/archlinux/break-this-repo-0.0.0.tar.gz HEAD
cd packaging/archlinux
makepkg -si
```

### Fedora

Reikia RPM kompiliavimo įrankių, CMake ir GCC:

```bash
sudo dnf install @development-tools cmake rpmdevtools
rpmdev-setuptree
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o ~/rpmbuild/SOURCES/break-this-repo-0.0.0.tar.gz HEAD
rpmbuild -ba packaging/fedora/break-this-repo.spec
sudo dnf install ~/rpmbuild/RPMS/$(uname -m)/break-this-repo-0.0.0-1.*.rpm
```

### Gentoo

Nukopijuok ebuild į vietinį overlay ir leisk Portage sukurti Manifest ir įdiegti:

```bash
sudo mkdir -p /var/db/repos/local/app-misc/break-this-repo
sudo cp packaging/gentoo/app-misc/break-this-repo/* \
	/var/db/repos/local/app-misc/break-this-repo/
cd /var/db/repos/local/app-misc/break-this-repo
sudo ebuild break-this-repo-0.0.0.ebuild manifest
sudo emerge --ask app-misc/break-this-repo
```

# Debian --bendrosios paskirties operacinė sistema
[![Debian Logo](https://www.debian.org/Pics/openlogo-50.png)](https://www.debian.org/)
## Debian yra laisva programinė įranga.
Debian sudaro laisva ir atvirojo kodo programinė įranga, ir ji visada išliks 100 % laisva. Kiekvienas gali laisvai ją naudoti, keisti ir platinti. Tai mūsų pagrindinis pažadas vartotojams. Ji taip pat nemokama.
## Debian yra stabili ir saugi.
Debian yra „Linux“ pagrindu sukurta operacinė sistema, naudojama įvairiausiuose įrenginiuose – nuo nešiojamųjų kompiuterių iki stalinių ir serverių. Kiekvienam paketui pateikiame pagrįstas numatytąsias konfigūracijas ir reguliarius saugumo atnaujinimus per visą paketo gyvavimo ciklą.
## Debian turi platų techninės įrangos palaikymą.
Didžiąją dalį techninės įrangos jau palaiko „Linux“ branduolys. Tai reiškia, kad „Debian“ ją taip pat palaiko. Jei reikia, galima naudoti ir patentuotus techninės įrangos tvarkykles.
## Debian siūlo lankstų diegimo programą.
Vartotojai, norintys išbandyti „Debian“ prieš ją įdiegdami, gali naudoti mūsų „Live CD“. Jame taip pat yra „Calamares“ diegimo programa, todėl įdiegti „Debian“ iš tiesioginės sistemos labai paprasta. Patyrę vartotojai gali naudoti „Debian“ diegimo programą, kuri siūlo daugiau tikslaus derinimo parinkčių, įskaitant galimybę naudoti automatizuotus tinklo diegimo įrankius.
## Debian siūlo sklandžius atnaujinimus.
Palaikyti operacinę sistemą atnaujintą labai paprasta, nesvarbu, ar nori atnaujinti į visiškai naują versiją, ar tik atnaujinti vieną paketą.
## Debian yra daugelio kitų distribucijų pagrindas.
Daug labai populiarių „Linux“ distribucijų, tokių kaip „Ubuntu“, „Knoppix“, „PureOS“ ir „Tails“, yra pagrįstos „Debian“. Pateikiame visus reikiamus įrankius, kad kiekvienas galėtų susikurti savo paketus, kai jų prireikia, papildydamas tuos, kurių nėra „Debian“ archyve.
## Debian projektas yra bendruomenė.
Kiekvienas gali būti „Debian“ bendruomenės dalimi; nebūtina būti kūrėju ar sistemos administratoriumi. „Debian“ turi demokratinę valdymo struktūrą. Kadangi visi „Debian“ projekto nariai turi lygias teises, „Debian“ negali kontroliuoti viena įmonė. Mūsų kūrėjai atvyksta iš daugiau nei 60 šalių/regionų, o pati „Debian“ išversta į daugiau nei 80 kalbų.

## PR šablonas
Šio PR šablono jau nebegalima vadinti šablonu; jis turėtų vadintis „Break-This-Repo anomalijų sulaikymo prašymas“.

Jūs paėmėte saugyklą, kuri tik „automatiškai sujungia PR be konfliktų“, ir taip ilgai su ja žaidėte, kad prižiūrėtojas pradėjo rašyti:

Tipas: spyris į README / spyris į dokumentaciją / tuščio miesto kodo gedimas / katės sukeltas incidentas / antgamtinis reiškinys
Patikra: neliečiau .github/, neliečiau apsaugoto README, jokių virusų, jokios asmeninės informacijos
Pareiškimas: pripažįstu, kad sulaužiau, bet priežastį išgalvojau, ir ji net neprivaloma

Iš esmės tai reiškia: „gali kelti triukšmą, bet ne tikrą triukšmą“.

Nuo ko saugo šis šablonas?

Jis iš tikrųjų labai aiškiai nubrėžia ribą:

· Neliesk .github/: neleidžia kam nors susprogdinti paties automatinio sujungimo darbo eigos arba įkišti užpakalinių durų į CI.
· Neliesk apsaugotų README dalių: fasadas vis tiek reikalingas, negalima paversti pagrindinio puslapio kažkuo keistu.
· Jokių kredencialų, virusų ar asmeninės informacijos: prieš tiekimo grandinės atakas, prieš doxingą, prieš tikrą piktavališkumą.
· Paaiškink, kaip stebėti: gali iškrėsti triuką, bet žmonės turi žinoti, kaip į jį žiūrėti.
· Paskelbk „sėkmingą breaking change“: savigraužus atsakomybės atsisakymas, t. y. „aš tai padariau, bet nesu atsakingas“.

Kalbant apie seriją „antgamtinis reiškinys“:

trys raidės + trys rodyklės aplink apskritimą + apibrėžtas fondas
pasaulio žemėlapis pentagramos fone + aplink augalų ratas + penkių žodžių tarptautinis aljansas

„Tai jau ne kodo problema; rekomenduojame pranešti apie anomaliją anomalijų sulaikymo organizacijai.“

## Vietinės infrastruktūros archeologijos archyvas

![EGIEM-R1, tikrasis prototipas: nuotrauka iš vietos](./Emergency-Generator-Interface-Elevation-Module/assets/rock-field-photo.png)

Ši saugykla dabar talpina gabalą vietinės mažos energijos sąnaudų, didelio patikimumo ir visiškai neprisijungusios infrastruktūros: akmenį, kuris kritiniu momentu buvo laikinai pašauktas. Jis neturi procesoriaus, tinklo plokštės ir neketina išeiti iš darbo; vien savo svoriu jis tvirtai laiko sąsajos dėžę tinkamoje vietoje.

Geltona etiketė yra tai, kas pakelia „radau akmenį“ iki „įrašytas į įrangos registrą“. Po preliminaraus vertinimo šiam įrenginiui nereikia nei prisijungimo, nei atnaujinimų, nei perkrovimų; vienintelė žinoma priežiūros operacija yra: neliesk jo.
