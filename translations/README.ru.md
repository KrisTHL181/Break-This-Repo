## Сборка из исходников

В репозитории несколько независимых точек сборки. Ставьте нужные инструменты и выполняйте команды в корне репозитория.

### C++ с Make

Нужен компилятор с поддержкой C++11:

```bash
make
```

Убрать артефакты сборки:

```bash
make clean
```

По умолчанию собираются `fozu` и `what`; на Windows ещё и `beep_win`.

### C++ с CMake

Нужны CMake 3.16 или новее и компилятор C++:

```bash
cmake -S . -B build/cmake
cmake --build build/cmake
```

### C++ с Meson

Нужны Meson, Ninja и компилятор C++:

```bash
meson setup build/meson
meson compile -C build/meson
```

### Python и Rust с maturin

Расширение для Python собирается на Rust с помощью [maturin](https://www.maturin.rs/). Нужны тулчейн Rust (вместе с `cargo`) и Python 3.13 или новее:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install maturin
```

В виртуальном окружении выполните любую из этих команд:

```bash
# собрать и установить в текущее виртуальное окружение
maturin develop

# собрать wheel-файл для распространения
maturin build --release
```

Готовые wheel-файлы лежат в `target/wheels/`. Входной код расширения на Rust — в [`src/lib.rs`](src/lib.rs), конфигурация сборки Python — в [`pyproject.toml`](pyproject.toml).

### TypeScript с Hereby

Часть на TypeScript лежит в `typescript/` и использует Node.js, npm и Hereby:

```bash
cd typescript
npm install
npm run build:compiler
```

Если нужно собрать и компилятор, и тестовые цели, выполните `npm run build`. Убрать артефакты сборки — `npm run clean`.

## Пакеты для дистрибутивов Linux

Шаблоны пакетов для дистрибутивов лежат в `debian/` и `packaging/`. Эти пакеты ставят консольные программы на C++ `fozu` и `what`; для расширений Python/Rust по-прежнему используйте процесс maturin, описанный выше. Единой open-source лицензии репозиторий пока не заявляет, поэтому перед официальным релизом сначала уточните и замените поля лицензии в файлах пакетов.

### Debian и Ubuntu

Нужны `dpkg-buildpackage`, Debhelper, CMake и GCC:

```bash
sudo apt update
sudo apt install build-essential cmake debhelper devscripts
dpkg-buildpackage -us -uc
sudo apt install ../break-this-repo_0.0.0_$(dpkg --print-architecture).deb
```

Можно также просто поставить уже собранный файл `.deb`:

```bash
sudo apt install ./break-this-repo_*.deb
```

### Arch Linux

Нужны `base-devel`, CMake и GCC. Сначала соберите из исходников архив, версия которого совпадает с `PKGBUILD`:

```bash
sudo pacman -S --needed base-devel cmake gcc
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o packaging/archlinux/break-this-repo-0.0.0.tar.gz HEAD
cd packaging/archlinux
makepkg -si
```

### Fedora

Нужны инструменты сборки RPM, CMake и GCC:

```bash
sudo dnf install @development-tools cmake rpmdevtools
rpmdev-setuptree
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o ~/rpmbuild/SOURCES/break-this-repo-0.0.0.tar.gz HEAD
rpmbuild -ba packaging/fedora/break-this-repo.spec
sudo dnf install ~/rpmbuild/RPMS/$(uname -m)/break-this-repo-0.0.0-1.*.rpm
```

### Gentoo

Скопируйте ebuild в локальный overlay, а дальше пусть Portage сгенерирует Manifest и поставит пакет:

```bash
sudo mkdir -p /var/db/repos/local/app-misc/break-this-repo
sudo cp packaging/gentoo/app-misc/break-this-repo/* \
	/var/db/repos/local/app-misc/break-this-repo/
cd /var/db/repos/local/app-misc/break-this-repo
sudo ebuild break-this-repo-0.0.0.ebuild manifest
sudo emerge --ask app-misc/break-this-repo
```

# Debian --универсальная операционная система
[![Debian Logo](https://www.debian.org/Pics/openlogo-50.png)](https://www.debian.org/)
## Debian — это свободное программное обеспечение.
Debian состоит из свободного программного обеспечения с открытым исходным кодом и всегда будет на 100% свободным. Каждый может свободно использовать его, изменять и распространять. Это наше главное обещание пользователям. И оно ещё и бесплатное.
## Debian стабилен и безопасен.
Debian — это операционная система на базе Linux, которая широко используется на самых разных устройствах: от ноутбуков и настольных компьютеров до серверов. Мы задаём разумные настройки по умолчанию для каждого пакета и выпускаем регулярные обновления безопасности в течение всего срока его поддержки.
## Debian поддерживает широкий спектр оборудования.
Большинство оборудования поддерживается ядром Linux. А значит, Debian тоже будет его поддерживать. При необходимости можно использовать и проприетарные драйверы для оборудования.
## Debian предлагает гибкую программу установки.
Тем, кто хочет попробовать Debian перед установкой, подойдёт наш Live CD. В него входит установщик Calamares, поэтому поставить Debian из Live-системы очень просто. Более опытные пользователи могут воспользоваться установщиком Debian: в нём больше параметров для тонкой настройки, включая возможность автоматизированной установки по сети.
## Debian обновляется безболезненно.
Держать операционную систему в актуальном состоянии очень просто — неважно, хотите вы обновиться до совсем нового релиза или обновить всего один пакет.
## Debian — основа многих других дистрибутивов.
Многие очень популярные дистрибутивы Linux, например Ubuntu, Knoppix, PureOS и Tails, основаны на Debian. Мы предоставляем все необходимые инструменты, чтобы каждый при необходимости мог собрать свои пакеты и дополнить ими архив Debian, если нужного пакета там нет.
## Проект Debian — это сообщество.
Стать частью сообщества Debian может кто угодно; быть разработчиком или системным администратором для этого не обязательно. У Debian демократическая модель управления. Поскольку все участники проекта Debian имеют равные права, Debian не может контролироваться одной компанией. Наши разработчики живут более чем в 60 странах и регионах, а сам Debian переведён более чем на 80 языков.

## Шаблон PR
Этот шаблон PR уже и шаблоном-то не назовёшь — скорее «Заявление на содержание аномалии в Break-This-Repo».

Вы всей этой толпой довели репозиторий, который «автоматически сливает PR без конфликтов», до того, что мейнтейнер начал писать:

Тип: пнуть README / пнуть документацию / сбой кода по пустой крепости / происшествие по вине кота / сверхъестественное явление
Проверка: я не трогал .github/, не трогал защищённый README, без вирусов, без личных данных
Заявление: признаю, что сломал, но причину я написал от балды, и вообще она необязательна

Это, по сути: «ломать можно, но по-настоящему ломать нельзя».

От чего защищает этот шаблон?

На самом деле он очень чётко очерчивает границы:

· Не трогать .github/: чтобы кто-нибудь не снёс сам воркфлоу автослияния или не засунул бэкдор в CI.
· Не трогать защищённые части README: витрина всё-таки нужна, нельзя превращать главную страницу в непонятно что.
· Никаких учётных данных, вирусов и личных данных: защита от атак на цепочку поставок, от деанона, от реального вреда.
· Объяснить, как за этим наблюдать: шутить можно, но люди должны понимать, как смотреть на твои шутки.
· Заявить «я успешно сделал breaking change»: самоироничный дисклеймер, что-то вроде «я это сделал, но я не в ответе».

Что до той строчки про «сверхъестественные явления»:

три буквы + три стрелки в круге + Фонд с обводкой
пятиконечная звезда на фоне карты мира + венок из колосьев + международный союз из пяти слов

Первое — это Фонд SCP, второе — вероятно, что-то вроде Продовольственной и сельскохозяйственной организации ООН / FAO. В переводе это значит:
«Это уже не проблема кода, рекомендуем доложить организации по содержанию аномалий».

Как приложить этот шаблон к своему коммиту?

Вы загружаете исходники Minecraft, OpenJDK, Fabric Loader, набиваете 4 коммита на 12 с лишним миллионов строк, а в типе можно отметить:

☑ пнул документацию
☑ сбой кода по пустой крепости (косплей Сюй Цзяинь)
☑ использовал Git на разных платформах
☐ происшествие по вине кота
☐ сверхъестественное явление

Все галочки в проверке, заявление копируете, а в причине пишете:

Причина: написана от балды, необязательна, но 12770942 строки кода всё-таки нужно куда-то пристроить.

Способ наблюдения:

Откройте OpenJDK_25.0.3, посмотрите историю коммитов и почувствуйте молчание объёма репозитория.

Но всё же напомню

Такие репозитории — это игровая площадка, а не место вне закона. Залить полные исходники OpenJDK или исходники Minecraft — это, может, и «автослияние без конфликтов», но оно ведёт к:
