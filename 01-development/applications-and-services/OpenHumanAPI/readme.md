# OpenHuman API

在本地创建 OpenAI 兼容的 chat completions (聊天补全) API 接口，并允许你在控制台中检查请求内容，并手动填写返回内容。

换言之，你可以把自己接入 codex/hermes/opencode/dsh/... 等平台并看看LLM之前是怎么工作的喵！

## 运行

要运行它，请安装[Deno](https://deno.com/)并使用`deno task start`

## 一些其他的碎碎念

- 本程序不提供流式输出能力（虽然兼容了流式输出的接口），再加上人类理解长串提示词的速度以及打字速度都不快，这个API的反应速度可能很慢喵
- 实际上，如果有别人用你提供的 OpenHuman API 接入了 Agent 框架，就相当于你远程连接了ta的电脑喵！
  虽然还是会受到 agent 框架对于工具调用的一些限制（比如沙箱），但是还是很好玩喵（？）
