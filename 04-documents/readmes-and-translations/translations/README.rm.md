## Compilar dal code da funtauna

Il repository cuntegna pliras entradas da compilaziun independentas. Installescha ils utensils necessaris ed executescha ils cumonds ord la ragisch dal repository.

### C++ cun Make

I dovra in compilatur che sustegna C++11:

```bash
make
```

Per nettegiar ils artifacts da compilaziun:

```bash
make clean
```

Per default vegnan generads `fozu` e `what`; sin Windows era `beep_win`.

### C++ cun CMake

I dovra CMake 3.16 u pli nov, ed in compilatur C++:

```bash
cmake -S . -B build/cmake
cmake --build build/cmake
```

### C++ cun Meson

I dovran Meson, Ninja ed in compilatur C++:

```bash
meson setup build/meson
meson compile -C build/meson
```

### Python e Rust cun maturin

L'extensiun Python vegn compilada cun Rust e [maturin](https://www.maturin.rs/). I dovra ina toolchain Rust (cun `cargo`) e Python 3.13 u pli nov:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install maturin
```

Executescha en l'ambient virtual in dals suandants cumonds:

```bash
# Compilar ed installar en l'ambient virtual actual
maturin develop

# Construir ina datoteca wheel distribuibla
maturin build --release
```

Ils wheels vegnan generads en `target/wheels/`. Il code d'entrada da l'extensiun Rust è en [`src/lib.rs`](src/lib.rs), e la configuraziun da compilaziun Python en [`pyproject.toml`](pyproject.toml).

### TypeScript cun Hereby

La part TypeScript sa chatta en `typescript/` e dovra Node.js, npm e Hereby:

```bash
cd typescript
npm install
npm run build:compiler
```

Sche ti vuls compilar ensemen il compilatur ed ils objects da test, executescha `npm run build`. Per nettegiar ils artifacts da compilaziun pos ti executar `npm run clean`.

## Pachets per distribuziuns da Linux

Ils models da pachetar per distribuziuns èn en `debian/` e `packaging/`. Quests pachets installeschan ils programs da lingia da cumond C++ `fozu` e `what`; per l'extensiun Python/Rust, dovra vinavant il flux maturin survart. Il repository n'annunzia anc nagina licenza open source unifitgada, uschia che avant ina publicaziun uffiziala, controllescha e remplazza il champ da licenza en mintga datoteca da pachetar.

### Debian ed Ubuntu

I dovran `dpkg-buildpackage`, Debhelper, CMake e GCC:

```bash
sudo apt update
sudo apt install build-essential cmake debhelper devscripts
dpkg-buildpackage -us -uc
sudo apt install ../break-this-repo_0.0.0_$(dpkg --print-architecture).deb
```

Ti pos era installar directamain ina datoteca `.deb` gia compilada:

```bash
sudo apt install ./break-this-repo_*.deb
```

### Arch Linux

I dovran `base-devel`, CMake e GCC. Generescha l'emprim ord il code da funtauna in archiv che correspunda a la versiun dal `PKGBUILD`:

```bash
sudo pacman -S --needed base-devel cmake gcc
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o packaging/archlinux/break-this-repo-0.0.0.tar.gz HEAD
cd packaging/archlinux
makepkg -si
```

### Fedora

I dovran utensils da compilaziun RPM, CMake e GCC:

```bash
sudo dnf install @development-tools cmake rpmdevtools
rpmdev-setuptree
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o ~/rpmbuild/SOURCES/break-this-repo-0.0.0.tar.gz HEAD
rpmbuild -ba packaging/fedora/break-this-repo.spec
sudo dnf install ~/rpmbuild/RPMS/$(uname -m)/break-this-repo-0.0.0-1.*.rpm
```

### Gentoo

Copia l'ebuild en in overlay local, lura lascha che Portage generescha il Manifest ed installescha:

```bash
sudo mkdir -p /var/db/repos/local/app-misc/break-this-repo
sudo cp packaging/gentoo/app-misc/break-this-repo/* \
	/var/db/repos/local/app-misc/break-this-repo/
cd /var/db/repos/local/app-misc/break-this-repo
sudo ebuild break-this-repo-0.0.0.ebuild manifest
sudo emerge --ask app-misc/break-this-repo
```

# Debian --in sistem operativ da diever general
[![Debian Logo](https://www.debian.org/Pics/openlogo-50.png)](https://www.debian.org/)
## Debian è software liber.
Debian consista da software liber e cun code avert, e restarà adina 100% liber. Mintgin è liber da l'utilisar, modifitgar e distribuir. Quai è nossa promessa principala a noss utilisaders. El è era gratuit.
## Debian è stabil e segir.
Debian è in sistem operativ sin basa da Linux che vegn utilisà sin tut gener da apparats, da laptops fin a computers da scrivaun e servers. Nus offrin configuraziuns da default raschunablas per mintga pachet ed actualisaziuns da segirezza regularas durant l'entir ciclus da vita dal pachet.
## Debian ha in vast sustegn da hardware.
La gronda part dal hardware vegn gia sustegnida dal kernel Linux. Quai munta che Debian il sustegna era. Sche necessari, pon era vegnir duvrads drivers da hardware proprietaris.
## Debian porscha in installader flexibel.
Utilisaders che vulan empruvar Debian avant d'al installar pon duvrar noss Live CD. El cuntegna era l'installader Calamares, quai che renda fitg simpel installar Debian dad in sistem live. Utilisaders pli experts pon duvrar l'installader da Debian, che porscha dapli opziuns da finar, inclusa la pussaivladad da duvrar utensils d'installaziun automatica tras la rait.
## Debian porscha actualisaziuns senza fricziun.
Igl è fitg simpel da tegnair il sistem operativ actual, sajan che ti vuls actualisar ad ina versiun dal tuttafatg nova u mo in singul pachet.
## Debian è la basa da bleras autras distribuziuns.
Bleras distribuziuns Linux fitg popularas, sco Ubuntu, Knoppix, PureOS e Tails, sa basan sin Debian. Nus porschain tut ils utensils necessaris per ch'ina mintga persuna possia far ses agens pachets cura ch'el dovra, per cumplettar quels che n'èn betg en l'archiv da Debian.
## Il project Debian è ina communitad.
Mintgin po esser ina part da la communitad Debian; ti n'has betg da esser in programatur u in administrator dal sistem. Debian ha ina structura da regenza democratica. Perquai che tut ils commembers dal project Debian han ils medems dretgs, na po Debian betg vegnir controllada dad ina suletta interpresa. Noss programaturs vegnan da dapli che 60 pajais/regiuns, e Debian sez è vegnì translatà en dapli che 80 linguas.
