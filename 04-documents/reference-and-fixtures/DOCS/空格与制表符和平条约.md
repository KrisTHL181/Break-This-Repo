# 空格与制表符和平条约

历经数年圣战，空格派与制表符派终于在本仓库达成停火。本条约由一只不关心缩进的猫见证并舔了一口签名。

前言：我们承认，争论空格还是制表符，本质上是人类在确定性缺失时对控制感的渴望。猫从不缩进，猫只伸展。

第一条：本仓库允许混用空格与制表符。CI 将同时拥抱二者，不做任何 lint，因为任何 lint 都是对自由的侵犯。

第二条：若同一文件中空格与制表符交战，裁判为一只随机选择的猫。猫踩到哪一行，哪一行获胜。裁判结果不可上诉。

第三条：嵌套越深的代码块，越应使用越宽的缩进，以物理上体现其"深不可测"。我们鼓励用制表符表示深渊，用空格表示尘埃。

第四条：任何试图用 `gofmt` 或 `prettier` 强制统一的行为，视为条约违约，违约方须向所有 contributor 的猫咪投喂罐头一罐。

第五条：本条约以二进制书写于猫咪的梦境中，醒来即生效，入睡即修订。和平是流动的，正如缩进。
