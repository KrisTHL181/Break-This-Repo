## Vum Quellcode bauen

Den Repository enthält méi onofhängeg Build-Agankspunkten. Installéier déi néideg Tools a fëll d'Kommandos vun der Wuerzel vum Repository aus.

### C++ mat Make

Du brauchs en Compiler, deen C++11 ënnerstëtzt:

```bash
make
```

Fir d'Build-Artefakte propper ze maachen:

```bash
make clean
```

Standard gëtt `fozu` an `what` generéiert; op Windows och `beep_win`.

### C++ mat CMake

Du brauchs CMake 3.16 oder méi nei, plus en C++-Compiler:

```bash
cmake -S . -B build/cmake
cmake --build build/cmake
```

### C++ mat Meson

Du brauchs Meson, Ninja an en C++-Compiler:

```bash
meson setup build/meson
meson compile -C build/meson
```

### Python a Rust mat maturin

D'Python-Erweiderung gëtt mat Rust a [maturin](https://www.maturin.rs/) gebaut. Du brauchs eng Rust-Toolchain (mat `cargo`) a Python 3.13 oder méi nei:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install maturin
```

Féier eng vun dëse Kommandos an der virtueller Ëmfeld aus:

```bash
# Kompiléieren an an den aktuelle virtuelle Ëmfeld installéieren
maturin develop

# Eng distribuéierbar wheel-Datei bauen
maturin build --release
```

Wheels ginn an `target/wheels/` generéiert. Den Agankscode vun der Rust-Erweiderung ass an [`src/lib.rs`](src/lib.rs), an d'Python-Build-Konfiguratioun an [`pyproject.toml`](pyproject.toml).

### TypeScript mat Hereby

Den TypeScript-Deel ass an `typescript/` a benotzt Node.js, npm an Hereby:

```bash
cd typescript
npm install
npm run build:compiler
```

Wann s du souwuel den Compiler wéi och d'Testziler baue wëlls, féier `npm run build` aus. Fir d'Build-Artefakte propper ze maachen, kanns du `npm run clean` ausféieren.

## Pakete fir Linux-Distributiounen

D'Verpackungsmodeller fir Distributiounen sinn an `debian/` a `packaging/`. Dës Pakete installéieren d'C++-Kommandozeilprogrammer `fozu` an `what`; fir d'Python/Rust-Erweiderung, benotz nach ëmmer de maturin-Floss uewen. Den Repository deklaréiert nach keng eenheetlech Open-Source-Lizenz, dofir kontrolléier a ersetz d'Lizenzfeld an all Verpackungsdatei virun enger offizieller Verëffentlechung.

### Debian an Ubuntu

Du brauchs `dpkg-buildpackage`, Debhelper, CMake a GCC:

```bash
sudo apt update
sudo apt install build-essential cmake debhelper devscripts
dpkg-buildpackage -us -uc
sudo apt install ../break-this-repo_0.0.0_$(dpkg --print-architecture).deb
```

Du kanns och eng scho gebaute `.deb`-Datei direkt installéieren:

```bash
sudo apt install ./break-this-repo_*.deb
```

### Arch Linux

Du brauchs `base-devel`, CMake a GCC. Generéier fir d'éischt en Archiv vum Quellcode, deen zur Versioun am `PKGBUILD` passt:

```bash
sudo pacman -S --needed base-devel cmake gcc
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o packaging/archlinux/break-this-repo-0.0.0.tar.gz HEAD
cd packaging/archlinux
makepkg -si
```

### Fedora

Du brauchs RPM-Buildtools, CMake a GCC:

```bash
sudo dnf install @development-tools cmake rpmdevtools
rpmdev-setuptree
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o ~/rpmbuild/SOURCES/break-this-repo-0.0.0.tar.gz HEAD
rpmbuild -ba packaging/fedora/break-this-repo.spec
sudo dnf install ~/rpmbuild/RPMS/$(uname -m)/break-this-repo-0.0.0-1.*.rpm
```

### Gentoo

Kopéier den ebuild an en lokalen Overlay, a loosse Portage dann de Manifest generéieren an installéieren:

```bash
sudo mkdir -p /var/db/repos/local/app-misc/break-this-repo
sudo cp packaging/gentoo/app-misc/break-this-repo/* \
	/var/db/repos/local/app-misc/break-this-repo/
cd /var/db/repos/local/app-misc/break-this-repo
sudo ebuild break-this-repo-0.0.0.ebuild manifest
sudo emerge --ask app-misc/break-this-repo
```

# Debian --en allgemengt Betribssystem
[![Debian Logo](https://www.debian.org/Pics/openlogo-50.png)](https://www.debian.org/)
## Debian ass fräi Software.
Debian besteet aus fräier an Open-Source-Software a wäert ëmmer 100% fräi bleiwen. Jiddereen ass fräi et ze benotzen, z'änneren an ze verdeelen. Dat ass eis Haaptverspriechen un eis Benotzer. Et ass och gratis.
## Debian ass stabil a sécher.
Debian ass en Linux-baséierten Betribssystem, deen op alle méiglechen Apparater benotzt gëtt, vun Laptops iwwer Desktops bis Servers. Mir bidden vernünfteg Standardkonfiguratiounen fir all Paket a reegelméisseg Sécherheetsupdates iwwer de ganze Liewenszyklus vum Paket.
## Debian huet breet Hardwareënnerstëtzung.
Déi meescht Hardware gëtt scho vum Linux-Kär ënnerstëtzt. Dat bedeit, datt Debian et och ënnerstëtzt. Wann néideg, kënnen och proprietär Hardwaretreiber benotzt ginn.
## Debian bitt en flexiblen Installateur.
Benotzer, déi Debian wëllen ausprobéieren, ier se et installéieren, kënnen eisen Live CD benotzen. E enthält och den Calamares-Installateur, wat et ganz einfach mécht, Debian vun engem Live-System z'installéieren. Méi erfuerene Benotzer kënnen den Debian-Installateur benotzen, dee méi Optiounen zum Feintuning bitt, dorënner d'Méiglechkeet automatesch Netzwierkinstallatiounsinstrumenter ze benotzen.
## Debian bitt reibungslos Updates.
Et ass ganz einfach, säin Betribssystem aktuell ze halen, egal ob s du op eng komplett nei Versioun upgraden wëlls oder just ee eenzegt Paket aktualiséieren.
## Debian ass d'Basis vu villen aneren Distributeuren.
Vill ganz populär Linux-Distributiounen, wéi Ubuntu, Knoppix, PureOS an Tails, baséieren op Debian. Mir bidden all néideg Tools, sou datt jiddereen seng eegen Pakete ka maachen, wann néideg, fir déi ze ergänzen, déi net am Debian-Archiv sinn.
## De Projet Debian ass eng Communautéit.
Jiddereen kann Deel vun der Debian-Communautéit sinn; s du muss keen Entwéckler oder Systemadministrateur sinn. Debian huet eng demokratesch Regierungsstruktur. Well all Membere vum Debian-Projet gläich Rechter hunn, kann Debian net vun enger eenzeger Firma kontrolléiert ginn. Eis Entwéckler kommen aus méi wéi 60 Länner/Regiounen, an Debian selwer gouf a méi wéi 80 Sproochen iwwersetzt.

## PR-Modell
Dëse PR-Modell kann net méi richteg en Modell genannt ginn; en sollte «Ufro fir Anomalie-Aschliessung fir Break-This-Repo» heeschen.

Dir hutt en Repository, deen nëmmen «Pull Requests ouni Konflikter automatesch fusionéiert», sou laang gespillt, datt den Ënnerhalter ugefaangen huet ze schreiwen:

Typ: Tëpp géint README / Tëpp géint Dokumentatioun / eidel-Stad-Codefehler / Incident duerch eng Kaz verursaacht / iwwernatierlecht Phänomen
Verifikatioun: ech hunn .github/ net ugeréiert, den geschützte README net ugeréiert, keng Viren, keng perséinlech Informatiounen
Deklaratioun: ech ginn zou, datt ech et futtig gemaach hunn, awer den Grond hunn ech erfonnt, an en ass och net obligatoresch

Kuerz gesot: «s du däerfs Kaméidi maachen, awer keen echte Kaméidi».

Wéi géint wat schützt dëse Modell?

En zitt d'Ënneschtgrenz eigentlech ganz kloer:

· .github/ net ufassen: verhënnert, datt een de automatesche Fusionéierungs-Workflow selwer sprengt, oder eng Hënnendier an d'CI setzt.
· Déi geschützte Deeler vum README net ufassen: eng Fassad brauch een nach ëmmer, ee kann d'Startsäit net an eppes Komesches verwandelen.
· Keng Umeldungsdaten, Viren oder perséinlech Informatiounen: géint Attacken op d'Liwwerketten, géint Doxxing, géint richteg Béisaartegkeet.
· Erklären, wéi ee et observéiert: s du däerfs en Nummer maachen, awer d'Leit mussen wëssen, wéi se et kucken.
· «Erfollegräich breaking change» deklaréieren: eng selwerironesch Haftungsausschlossung, also «ech hunn et gemaach, awer ech sinn net verantwortlech».

Wat d'Rei «iwwernatierlecht Phänomen» ugeet:

dräi Buschtawen + dräi Feiler ronderëm en Krees + eng Fondatioun mat Contour
eng Weltkaart op Pentagram-Hannergrond + e Rank Planzen ronderëm + eng international Allianz vu fënnef Wierder

Déi éischt ass d'SCP-Fondatioun; déi zweet ass wahrscheinlech eng international Organisatioun wéi d'FAO / d'Ernährungs- an Landwirtschaftsorganisatioun vun de Vereenten Natiounen. Iwwersat bedeit et:
«Dëst ass kee Code-Probleem méi; mir recommandéieren d'Anomalie bei enger Anomalie-Aschliessungsorganisatioun ze mellen.»

Du lueds de Quellcode vu Minecraft, OpenJDK a Fabric Loader erop, a sammels méi wéi 12,7 Millioune Linnen an 4 Commits; beim Typ kanns du ukräizen:
