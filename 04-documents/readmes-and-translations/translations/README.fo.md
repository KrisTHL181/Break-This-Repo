## Bygg frá keldukodinum

Repositoryið inniheldur fleiri óheftar byggjeinngangar. Set tær neyðugu tólamar upp og koyr boðini frá rótini av repositorynum.

### C++ við Make

Tú hevur tørv á einum kompilator sum stuðlar C++11:

```bash
make
```

Fyri at rudda byggjatilfar:

```bash
make clean
```

Vanliga verða `fozu` og `what` gjørd; í Windows eisini `beep_win`.

### C++ við CMake

Tú hevur tørv á CMake 3.16 ella nýggjari, og einum C++ kompilator:

```bash
cmake -S . -B build/cmake
cmake --build build/cmake
```

### C++ við Meson

Tú hevur tørv á Meson, Ninja og einum C++ kompilator:

```bash
meson setup build/meson
meson compile -C build/meson
```

### Python og Rust við maturin

Python víðkanin verður bygd við Rust og [maturin](https://www.maturin.rs/). Tú hevur tørv á einari Rust verkføriskeðu (við `cargo`) og Python 3.13 ella nýggjari:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install maturin
```

Í tí virtuela umhvørvinum koyr eitt av hesum boðunum:

```bash
# Kompilera og set upp í núverandi virtuela umhvørvi
maturin develop

# Bygg eina býttandi wheel fílu
maturin build --release
```

Wheel fílur verða gjørdar í `target/wheels/`. Inngangskodin hjá Rust víðkanini er í [`src/lib.rs`](src/lib.rs), og Python byggjkonfigurationin í [`pyproject.toml`](pyproject.toml).

### TypeScript við Hereby

TypeScript parturin er í `typescript/` og brúkar Node.js, npm og Hereby:

```bash
cd typescript
npm install
npm run build:compiler
```

Vilt tú byggja bæði kompilatorin og testmálini, koyr tá `npm run build`. Fyri at rudda byggjatilfar kanst tú koyra `npm run clean`.

## Pakkar fyri Linux útbýtingar

Pakkamynstur fyri útbýtingar eru í `debian/` og `packaging/`. Hesi pakkarnir seta upp C++ kommandolínjuforritini `fozu` og `what`; fyri Python/Rust víðkanina brúka enn maturin ferðina omanfyri. Repositoryið kunngerðir enn ikki eina sameinandi open source lisens, so vátta og skift út lisensfeltið í hvørji pakkafílu fyri eina almenna útgávu.

### Debian og Ubuntu

Tú hevur tørv á `dpkg-buildpackage`, Debhelper, CMake og GCC:

```bash
sudo apt update
sudo apt install build-essential cmake debhelper devscripts
dpkg-buildpackage -us -uc
sudo apt install ../break-this-repo_0.0.0_$(dpkg --print-architecture).deb
```

Tú kanst eisini seta eina longu bygda `.deb` fílu upp beinleiðis:

```bash
sudo apt install ./break-this-repo_*.deb
```

### Arch Linux

Tú hevur tørv á `base-devel`, CMake og GCC. Ger fyrst eitt arkiv frá keldukodinum sum passar versjónini í `PKGBUILD`:

```bash
sudo pacman -S --needed base-devel cmake gcc
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o packaging/archlinux/break-this-repo-0.0.0.tar.gz HEAD
cd packaging/archlinux
makepkg -si
```

### Fedora

Tú hevur tørv á RPM byggitólamar, CMake og GCC:

```bash
sudo dnf install @development-tools cmake rpmdevtools
rpmdev-setuptree
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o ~/rpmbuild/SOURCES/break-this-repo-0.0.0.tar.gz HEAD
rpmbuild -ba packaging/fedora/break-this-repo.spec
sudo dnf install ~/rpmbuild/RPMS/$(uname -m)/break-this-repo-0.0.0-1.*.rpm
```

### Gentoo

Avrita ebuild inn í eitt lokalt overlay og lat so Portage gera Manifest og seta upp:

```bash
sudo mkdir -p /var/db/repos/local/app-misc/break-this-repo
sudo cp packaging/gentoo/app-misc/break-this-repo/* \
	/var/db/repos/local/app-misc/break-this-repo/
cd /var/db/repos/local/app-misc/break-this-repo
sudo ebuild break-this-repo-0.0.0.ebuild manifest
sudo emerge --ask app-misc/break-this-repo
```

# Debian --eitt almenn operativskipan
[![Debian Logo](https://www.debian.org/Pics/openlogo-50.png)](https://www.debian.org/)
## Debian er frítt software.
Debian er sett saman av fríum og opnum keldukoda software og verður altíð 100 % frítt. Einhvør kann frítt brúka, broyta og býta tað. Hetta er okkara høvuðsloforð til okkara brúkarar. Tað er eisini ókeypis.
## Debian er støðugt og trygt.
Debian er ein Linux grundað operativskipan sum verður brúkt á allskyns tólum, frá fartølum til borðtøl og ambætarar. Vit bjóða skilagóðar standardstillingar fyri hvønn pakka og regluligar trygdardagføringar ígjøgnum allan lívstíðarring pakkans.
## Debian hevur breiðan hardware stuðul.
Mest av hardware verður longu stuðlað av Linux kjarnanum. Tað merkir at Debian eisini stuðlar tí. Um neyðugt kann eisini brúkast sereygin hardware drivari.
## Debian bjóðar ein foyniligan installatør.
Brúkarar sum vilja royna Debian áðrenn teir seta tað upp kunnu brúka okkara Live CD. Tað inniheldur eisini Calamares installatørin, sum ger tað sera lætt at seta Debian upp frá eini livandi skipan. Meira royndir brúkarar kunnu brúka Debian installatørin, sum bjóðar fleiri møguleikar at fínstilla, eitt nú at brúka sjálvvirkandi netinstallatør.
## Debian bjóðar sløttar dagføringar.
Tað er sera lætt at halda operativskipanini dagførdari, antin tú vilt dagføra til eina heilt nýggja útgávu ella bara ein einstakan pakka.
## Debian er grundarlagið undir nógvum øðrum útbýtingum.
Nógvar sera umtóktar Linux útbýtingar, sum Ubuntu, Knoppix, PureOS og Tails, eru grundaðar á Debian. Vit bjóða øll neyðugu tólamar so at einhvør kann gera sínar egnu pakkar tá tað tørvar, at bøta um teir sum ikki eru í Debian arkivinun.
## Debian verkætlanin er ein felagsskapur.
Einhvør kann vera partur av Debian felagsskapinum; tú mást ikki vera mennari ella skipanarstjóri. Debian hevur eina demokratiska stýrisskipan. Tí at allir limir í Debian verkætlanini hava somu rættindi, kann Debian ikki verða stýrt av einum einstøkum fyritøku. Okkara mennarar koma frá meira enn 60 londum/økjum, og Debian sjálvt er umsett til meira enn 80 mál.

## PR mynstur
Hetta PR mynstrið kann ikki longur rættiliga kallast eitt mynstur; tað skuldi heitað «Umsókn um ónáttúrligheidshald fyri Break-This-Repo».

Tit hava tikið eitt repository sum bara «samanfatar PR uttan konfliktir sjálvvirkandi» og leikað so nógv við tað at viðlíkahaldarin byrjaði at skriva:

Slag: spark til README / spark til skjal / brestur í kodun hjá tómari býur / hending orsakað av katti / yvirmáttúrlig fyribrigdi
Váttan: eg rørdi ikki .github/, rørdi ikki vardað README, eingin virus, eingin persónlig upplýsing
Yvirlýsing: eg viðurkenni at eg breyt tað, men orsøkina fann eg upp, og hon er ikki einaferð skyldug

Í stuttum: «tú mást gera ófrið, men ikki veruligan ófrið».

Hvat verndar hetta mynstrið ímóti?

Tað drar markið í grundini sera greitt:

· Ikki røra .github/: forðar einum at sprongja sjálva sjálvvirkandi samanfatanar arbeiðsflóðina, ella at seta ein bakdyr inn í CI.
· Ikki røra vardu partarnar av README: ein fasada tørvar enn, tú kanst ikki gera heimasíðuna til nakað løgið.
· Eingi innritanartøk, virus ella persónlig upplýsing: ímóti árásum á veitingarkeðjuna, ímóti doxxing, ímóti veruligari illvilja.
· Greið frá hvussu ein hyggur at: tú mást gera eitt nummar, men fólk mugu vita hvussu tey hyggja at tí.
· Yvirlýs «eydnuklassan breaking change»: ein sjálvironisk fráskriving av ábyrgd, tað er «eg gjørdi tað, men eg eri ikki ábyrgdur».

Hvat viðvíkur røðini «yvirmáttúrlig fyribrigdi»:

tríggir bókstavir + tríggir pílar kring ein kring + ein stovnur við útlínum
heimskort á pentagram bakgrund + ein kransur av grøði kring + ein altjóða samgonga av fimm orðum

Tann fyrri er SCP stovnurin; tann seinni er helst ein altjóða samskipan sum FAO / Matvøru- og landbúnaðarsamskipan Sameindu Tjóða. Umsett merkir tað:
«Hetta er ikki longur eitt kodutrupulleiki; vit mæla til at melda frábrigdið til eina samskipan fyri frábrigdishald.»

Hvussu kann commit títt passa inn í hetta mynstrið?

Tú leggur keldukodin hjá Minecraft, OpenJDK og Fabric Loader upp, savnar meira enn 12,7 milliónir linjur í 4 committum; undir slagi kanst tú krossa av:

☑ spark til skjalið
☑ brestur í kodun hjá tómari býur (cosplay av Xu Jiayin)
☑ Git yvir fleiri pallar
☐ hending orsakað av katti
☐ yvirmáttúrlig fyribrigdi

Tú krossar av allar váttanir, avritar yvirlýsingina, og sum orsøk skrivar tú:

Orsøk: uppfunnið, ikki skyldug, men 12.770.942 linjur av kodu eiga kortini ein tittul.

Hvussu ein hyggur at:

Lat OpenJDK_25.0.3 upp, hygg at commit søguni, og kenn so tøgnina frá støddini av repositorynum.

Men ein ávaring er kortini á sínum stað

Hesi slagið av repository er ein spælipláss, ikki eitt lógloyst øki. At leggja allan OpenJDK keldukoda ella Minecraft keldukoda upp gevur møguliga bara eina «konfliktleysa sjálvvirkandi samanfatan», men hevur við sær:

· støddin av repositorynum sprongur, og GitHub kann avmarka ella ávara;
· upphavsrættar-/lisensspurningar: ikki allur keldukodi kann bara verða kastaður hvørgi;
· um onkur brúkar hetta repository sum treyt, er tað ein katastrofa í veitingarkeðjuni.

So niðurstøðan er:
hetta PR mynstrið er javnvágarmarkið sum viðlíkahaldarin fann millum «opna oyðilegging» og «at forða eini veruligari spronging».

## Fornfrøðiligt skjal um innviðirnar á staðnum

![EGIEM-R1, tann veruligi frumgerðin: mynd frá staðnum](./Emergency-Generator-Interface-Elevation-Module/assets/rock-field-photo.png)

Hetta repository hýsir nú eitt stykki av innviðum á staðnum við lítlum nýtslu, høgari álitiligheit og heilt uttan net: ein steinur sum var fyribils kallaður út á einum kritiskum tíðspunkti. Hann hevur onga CPU, einki netkort og onga ætlan at siga upp; bara við sínum egna vekt heldur hann millumstykkis-boxinum støðugt á røttum staði.

Tann guli merkimiðin er tað sum upphevar «eg tók ein stein upp» til «skrásett í tóla skránni». Eftir eina fyrst meting tørvar hetta tólið hvørki innritan, dagføringar ella endurbyrjan; einasta kenda viðlíkahaldsgerðin er: rør ikki við tí.

Treyt omanfyri: millumstykkis-box hjá generatorinum hjá operatørinum
