## البناء من المصدر

يحتوي المستودع على عدة مداخل بناء مستقلة. ثبّتوا الأدوات المطلوبة حسب الحاجة، ونفّذوا الأوامر من جذر المستودع.

### C++ مع Make

تحتاج إلى مُصرِّف يدعم C++11:

```bash
make
```

لتنظيف نواتج البناء:

```bash
make clean
```

يُنتج افتراضيًا `fozu` و`what`؛ وعلى Windows يُنتج كذلك `beep_win`.

### C++ مع CMake

تحتاج إلى CMake إصدار 3.16 أو أحدث، وإلى مترجم C++:

```bash
cmake -S . -B build/cmake
cmake --build build/cmake
```

### C++ مع Meson

تحتاج إلى Meson وNinja ومترجم C++:

```bash
meson setup build/meson
meson compile -C build/meson
```

### Python وRust مع maturin

إضافة Python مبنية بلغة Rust وبـ [maturin](https://www.maturin.rs/). تحتاج إلى سلسلة أدوات Rust (تتضمن `cargo`) وإلى Python 3.13 أو أحدث:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install maturin
```

نفّذ أيًّا من الأمرين التاليين داخل البيئة الافتراضية:

```bash
# ترجمة وتثبيت في البيئة الافتراضية الحالية
maturin develop

# بناء ملف wheel قابل للتوزيع
maturin build --release
```

ناتج بناء الـ wheel تجده في `target/wheels/`. كود مدخل إضافة Rust موجود في [`src/lib.rs`](src/lib.rs)، وإعدادات بناء Python في [`pyproject.toml`](pyproject.toml).

### TypeScript مع Hereby

جزء TypeScript موجود في `typescript/`، ويستخدم Node.js وnpm وHereby:

```bash
cd typescript
npm install
npm run build:compiler
```

لو أردت بناء المترجم وأهداف الاختبار معًا، نفّذ `npm run build`. ولتنظيف نواتج البناء نفّذ `npm run clean`.

## حزم توزيعات Linux

قوالب تغليف التوزيعات موجودة في `debian/` و`packaging/`. هذه الحزم تثبّت برنامجي سطر الأوامر المكتوبين بـ C++ وهما `fozu` و`what`؛ أما إضافة Python/Rust فاستخدم معها مسار maturin الموضح أعلاه. المستودع لا يصرّح حاليًا بترخيص مفتوح المصدر موحّد، لذا تأكّد أولًا من حقل الترخيص في كل ملف تغليف واستبدله قبل أي إصدار رسمي.

### Debian وUbuntu

تحتاج إلى `dpkg-buildpackage` وDebhelper وCMake وGCC:

```bash
sudo apt update
sudo apt install build-essential cmake debhelper devscripts
dpkg-buildpackage -us -uc
sudo apt install ../break-this-repo_0.0.0_$(dpkg --print-architecture).deb
```

يمكنك كذلك تثبيت ملف `.deb` المبني مباشرة:

```bash
sudo apt install ./break-this-repo_*.deb
```

### Arch Linux

تحتاج إلى `base-devel` وCMake وGCC. أولًا أنشئ من الشيفرة المصدرية أرشيفًا يطابق إصدار `PKGBUILD`:

```bash
sudo pacman -S --needed base-devel cmake gcc
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o packaging/archlinux/break-this-repo-0.0.0.tar.gz HEAD
cd packaging/archlinux
makepkg -si
```

### Fedora

تحتاج إلى أدوات بناء RPM وCMake وGCC:

```bash
sudo dnf install @development-tools cmake rpmdevtools
rpmdev-setuptree
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o ~/rpmbuild/SOURCES/break-this-repo-0.0.0.tar.gz HEAD
rpmbuild -ba packaging/fedora/break-this-repo.spec
sudo dnf install ~/rpmbuild/RPMS/$(uname -m)/break-this-repo-0.0.0-1.*.rpm
```

### Gentoo

انسخ الـ ebuild إلى overlay محلي، ثم دع Portage يولّد الـ Manifest ويثبّت الحزمة:

```bash
sudo mkdir -p /var/db/repos/local/app-misc/break-this-repo
sudo cp packaging/gentoo/app-misc/break-this-repo/* \
	/var/db/repos/local/app-misc/break-this-repo/
cd /var/db/repos/local/app-misc/break-this-repo
sudo ebuild break-this-repo-0.0.0.ebuild manifest
sudo emerge --ask app-misc/break-this-repo
```

# Debian — نظام تشغيل للأغراض العامة
[![Debian Logo](https://www.debian.org/Pics/openlogo-50.png)](https://www.debian.org/)
## Debian برنامج حر.
يتكوّن Debian من برمجيات حرة ومفتوحة المصدر، وسيبقى حرًّا بنسبة 100% دائمًا. للجميع الحرية في استخدامه وتعديله وتوزيعه. هذا هو تعهدنا الأساسي لمستخدمينا. وهو مجاني أيضًا.
## Debian مستقر وآمن.
Debian هو نظام تشغيل مبني على Linux يُستخدم على نطاق واسع في شتّى الأجهزة، من الحواسيب المحمولة والمكتبية إلى الخوادم. نوفّر لكل حزمة إعدادات افتراضية معقولة، ونوفّر تحديثات أمنية منتظمة طوال دورة حياة الحزمة.
## Debian يتمتع بدعم واسع للأجهزة.
معظم العتاد يحظى بدعم نواة Linux، وهذا يعني أن Debian سيدعمه أيضًا. وعند الحاجة يمكن استخدام برامج تشغيل عتاد خاصة.
## Debian يوفّر مثبّتًا مرنًا.
من يريد تجربة Debian قبل التثبيت يمكنه استخدام Live CD، فهو يتضمّن أيضًا مثبّت Calamares الذي يجعل تثبيت Debian من النظام الحيّ أمرًا سهلًا جدًّا. أما المستخدمون الأكثر خبرة فيمكنهم استخدام مثبّت Debian الذي يوفّر خيارات أكثر قابلة للضبط الدقيق، بما في ذلك إمكانية استخدام أدوات التثبيت الشبكية الآلية.
## Debian يوفّر تحديثات سلسة.
إبقاء نظام التشغيل محدَّثًا أمر سهل جدًّا، سواء أردت الترقية إلى إصدار جديد كليًّا أم أردت فقط ترقية حزمة واحدة بعينها.
## Debian هو أساس العديد من التوزيعات الأخرى.
كثير من توزيعات Linux الشائعة جدًّا، مثل Ubuntu وKnoppix وPureOS وTails، مبنية على Debian. وقد وفّرنا كل الأدوات اللازمة حتى يستطيع أي شخص، عند الحاجة، أن يصنع حزمه الخاصة ليُكمل بها الحزم غير الموجودة في أرشيف Debian.
## مشروع Debian هو مجتمع.
بإمكان أي شخص أن يصبح عضوًا في مجتمع Debian؛ لا يلزمك أن تكون مطوّرًا أو مدير أنظمة. ولدى Debian بنية حوكمة ديمقراطية، ولأن جميع أعضاء مشروع Debian يتمتعون بحقوق متساوية، فلا يمكن لأي شركة بمفردها أن تتحكّم في Debian. مطوّرونا يأتون من أكثر من 60 دولة/منطقة، وقد تُرجم Debian نفسه إلى أكثر من 80 لغة.

## قالب الـ PR
قالب الـ PR هذا ما عاد يصلح يُسمّى قالبًا، المفروض يُسمّى "طلب إيداع ظواهر شاذة في Break-This-Repo".

يا جماعة، أنتم حرفيًّا أخذتم مستودعًا "يدمج الـ PR تلقائيًّا بلا تعارض"، ولعبتم به حتى صار المشرف يكتب:

النوع: رفسة للـ README / رفسة للوثائق / عطل برمجي على طريقة المدينة الفارغة / حادثة سببها قط / ظواهر خارقة للطبيعة
التحقّق: أنا لم أمسّ .github/، ولم أمسّ الجزء المحمي من README، ولا فيروس، ولا معلومات شخصية
الإقرار: أعترف أنني خرّبت، لكن السبب كتبته على البركة، وهو غير ضروري

هذا باختصار يعني: "ممكن تخرّب، بس لا تخرّب خرابًا حقيقيًّا."

هذا القالب يحمي من إيش بالضبط؟

هو في الحقيقة يرسم الخط الأحمر بوضوح شديد:

· لا تمسّ .github/: حتى لا يجيء أحدهم ويطيح بسير عمل الدمج التلقائي نفسه، أو يزرع بابًا خلفيًّا في CI.
· لا تمسّ الجزء المحمي من README: الواجهة لازم تبقى، ما ينفع تتحوّل الصفحة الرئيسية إلى شيء غريب.
· لا بيانات اعتماد ولا فيروسات ولا معلومات شخصية: حماية من هجمات سلسلة التوريد، ومن التنقيب عن الأشخاص، ومن الشر الخالص.
· اشرح كيف يُراقَب الأمر: لك أن تتفرّج وتلعب، لكن يجب أن تعرف الناس كيف يشاهدونك وأنت تلعب.
· أعلن "أحدثت breaking change بنجاح": إخلاء مسؤولية ساخر من النفس، معناه "أنا سوّيتها، بس ما أتحمّل المسؤولية".

أما ذاك السطر "ظواهر خارقة للطبيعة":

ثلاثة أحرف + ثلاثة أسهم داخل دائرة + مؤسسة ذات حدود مرسومة
خلفية خريطة عالم بنجمة خماسية + دائرة محاصيل حولها + تحالف دولي من خمس كلمات

الأول هو مؤسسة SCP، والثاني على الأرجح منظمة دولية مثل منظمة الأغذية والزراعة / FAO. وبالترجمة يعني:
"المسألة ما عادت مسألة كود، الاقتراح أن تُرفع إلى منظمة احتواء الظواهر الشاذة."
