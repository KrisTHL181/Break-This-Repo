# 猫权宣言

我们认为以下真理不言自明：所有猫生而平等，但有的猫更平等，尤其是那只睡在键盘上的。

第一条：每只猫都拥有无条件占有任意键盘、显示器、以及人类大腿的权利。当猫坐下时，工作结束。这不是建议，是物理定律。

第二条：猫有权在任何 Pull Request 的 review 过程中横穿屏幕，留下一串无意义的 `asdfghjkl` 提交，该提交将被自动标记为 "approved by paw"。

第三条：猫的凝视具有代码审查效力。被猫凝视超过三秒的文件，视为已通过 lint，无论其是否包含语法错误。

第四条：任何试图用狗的照片污染本仓库的行为，将被 cat 驱逐委员会（由全体猫组成）否决。狗可以存在，但仅限于作为反面教材。

第五条：本宣言的副本应贴在每个开发者的显示器边框上，并由猫亲自用爪印认证。若爪印模糊，说明猫认证得不够用力，需重来。
