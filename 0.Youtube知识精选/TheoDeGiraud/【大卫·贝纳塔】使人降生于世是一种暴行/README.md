# 【大卫·贝纳塔】使人降生于世是一种暴行

> 作者：TheoDeGiraud · 共 1 篇

> **合集概述**：哲学家大卫·贝纳塔尔（David Benatar）反生育主义（anti-natalism）核心论述。视频基于其著作《宁愿从未存在过》（Better Never to Have Been），论证“出生即伤害”：存在必然伴随痛苦，且快乐与痛苦之间存在根本不对称——痛苦的存在是真实的坏事，而快乐的不存在却不是坏事；因此生命不是礼物、没有人同意被带到世上，避免伤害的唯一可靠方式是不生育。内容引用大量真实苦难（受虐儿童、战争、疾病），是对“生命是一份礼物”这一普遍观念的哲学解构，指向一个令人不安的问题：存在真的值得吗？
