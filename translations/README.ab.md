## Иарықәшә аҟынтәи абжьара

Ари репозитор ирылацәу абжьара аҩбаҩцәа еиҿацәаны иоуп. Иаҿыцу аҩбатәи аинструментқәа шәалаҟаҵаз, репозитор аиҿацәаҩ аҟны акомандқәа шәахьеит.

### C++ аMake-ҟны

C++11 иалазыҟоу акомпилатор шәалаҟаҵаҩуп:

```bash
make
```

Абжьара аԥштәы аҟаҵара:

```bash
make clean
```

Адефаулт ала `fozu` а `what` иаҵоуп; Windows аҟны `beep_win` ҳәа иаҵоуп.

### C++ аCMake-ҟны

CMake 3.16 ҩбатәи аверсиа, ма иара инаркны, C++ акомпилатор ҳәа шәалаҟаҵаҩуп:

```bash
cmake -S . -B build/cmake
cmake --build build/cmake
```

### C++ аMeson-ҟны

Meson, Ninja а C++ акомпилатор шәалаҟаҵаҩуп:

```bash
meson setup build/meson
meson compile -C build/meson
```

### Python аRust аmaturin-ҟны

Python аекстенсиа Rust а [maturin](https://www.maturin.rs/)-ҟны иҧшаахоит. Rust аинструментқәа (`cargo` иалаҵо) а Python 3.13 ҩбатәи ма иара инаркны шәалаҟаҵаҩуп:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install maturin
```

Авиртуалтәи аенвиронмент аҟны акомандқәа руак рҟныҟны зқәеиҭаҩ аҩбатәи шәахьеит:

```bash
# Ари авиртуалтәи аенвиронмент аҟны акомпилациа азуп аиҭагара
maturin develop

# Аиҭаҭра зылшо wheel-фаил аԥҟара
maturin build --release
```

Wheel абжьара аԥштәы `target/wheels/` аҟны иоуп. Rust аекстенсиа аҵакыларатә код [`src/lib.rs`](src/lib.rs) аҟны, Python абжьара аконфигурациа [`pyproject.toml`](pyproject.toml) аҟны иоуп.

### TypeScript аHereby-ҟны

TypeScript аҿакы `typescript/` аҟны иоуп, Node.js, npm а Hereby ҳәа ирхоит:

```bash
cd typescript
npm install
npm run build:compiler
```

Акомпилатор а тест ацельқәа зегьы змаҵ абжьара иҭаҵаз, `npm run build` шәахьеит. Абжьара аԥштәы аҟаҵара `npm run clean` шәахьеит.

## Linux адиcтрибуциақәа рзы апаκетқәа

Адиcтрибуциа апаκетқәа ршаблонқәа `debian/` а `packaging/` аҟны иоуп. Ари апаκетқәа C++ акомандтәи аԥрограмма `fozu` а `what` иҟанҵоит; Python/Rust аекстенсиақәа амаҭәарҭынтәи maturin аҩбатәи аҟаҵара хархәоит. Ари репозитор амома адиндоу алицензиа уажәҭан иалзеиуам, аофициалтәи аҽыҟаҵаҩ аҟны апаκетқәа зегьы рҟны алицензиа аполе шәаԥшаҧшьтәуп.

### Debian аUbuntu

`dpkg-buildpackage`, Debhelper, CMake а GCC шәалаҟаҵаҩуп:

```bash
sudo apt update
sudo apt install build-essential cmake debhelper devscripts
dpkg-buildpackage -us -uc
sudo apt install ../break-this-repo_0.0.0_$(dpkg --print-architecture).deb
```

Иара аҧҟәшьы иҧшааз `.deb`-фаилқәа шәаҟанҵоуп:

```bash
sudo apt install ./break-this-repo_*.deb
```

### Arch Linux

`base-devel`, CMake а GCC шәалаҟаҵаҩуп. Аҩныҟа `PKGBUILD` аверсиа ианамзы аархив аԥҟәшьы аҟнытәи исшиаз:

```bash
sudo pacman -S --needed base-devel cmake gcc
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o packaging/archlinux/break-this-repo-0.0.0.tar.gz HEAD
cd packaging/archlinux
makepkg -si
```

### Fedora

RPM абжьара аинструмент, CMake а GCC шәалаҟаҵаҩуп:

```bash
sudo dnf install @development-tools cmake rpmdevtools
rpmdev-setuptree
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o ~/rpmbuild/SOURCES/break-this-repo-0.0.0.tar.gz HEAD
rpmbuild -ba packaging/fedora/break-this-repo.spec
sudo dnf install ~/rpmbuild/RPMS/$(uname -m)/break-this-repo-0.0.0-1.*.rpm
```

### Gentoo

А ebuild шәахьатәи overlay аҟны шәаиҟаҵеит, анаҩс Portage иа Manifest исшәеит аҟанҵара:

```bash
sudo mkdir -p /var/db/repos/local/app-misc/break-this-repo
sudo cp packaging/gentoo/app-misc/break-this-repo/* \
	/var/db/repos/local/app-misc/break-this-repo/
cd /var/db/repos/local/app-misc/break-this-repo
sudo ebuild break-this-repo-0.0.0.ebuild manifest
sudo emerge --ask app-misc/break-this-repo
```

# Debian --ауниверсалтәи аоперационтәи система
[![Debian аэмблема](https://www.debian.org/Pics/openlogo-50.png)](https://www.debian.org/)
## Debian аԥсадгьылтәи аиҿацәаҩ ауп.
Debian аԥсадгьылтәи а открытәи ацәаҳәа ала иҧшаахоит, а 100% аԥсадгьылтәи ауп. Зқәеиҭаҩ зегьы хархәо, аихшьра, а ҟанҵара зегьы хархәо. Ари ҳәа хәышәтәҩцәа рзы ҳәа иҿыцу аԥҟара ауп. Иара ҳәа аҩбаҩ ауп.
## Debian аилазаарам, анаԥхаратәиуп.
Debian Linux иалаз аоперационтәи асистема ауп, иҧсадгьылтәи аҳаршақәа рзы бзиа ихархәо. Лаптоҭ, адесктоҭ, асерверқәа рзы. Зегьы апаκет азы абзиаратәи адефаулт-конфигурациа ҳәа иаҵоуп, апаκет азыҟазаашьа аҳаҧшьаратәи аҟаҵарақәа рзы.
## Debian аҳаршақәа рзы агуара бзиа змоу боу амоуп.
Аҳаршақәа зегьы Linux аkernel иалаз. Уи Debian ҳәа иаларгуеит. Иҟоу азы, аԥроприетартәи аҳарша аԥшаҩқәа ҳәа хархәо.
## Debian иаԥсаху аиҿаргыларатә программа анаԥоит.
Debian аиҿаргылараз аԥхьа азыҟазаашьа ахархәо ахьӡынҭәалаҩқәа ҳәа хәа Live CD хархәо. Ари Calamares аиҿаргыларатә программа иалаз, Live асистема аҟны Debian аиҿаргылара бзиа имоуп. Иаԥсаху ахьӡынҭәалаҩҩа Debian аиҿаргыларатә программа хархәо, аҩбаҩ аопциақәа роуп, аавтоматтәи ацәаҳәанӡара аҟаҵара хархәо.
## Debian аӡәы аҟаҵара анаԥоит.
Аоперационтәи асистема ашьаҟаԥшьы аҟаҵара бзиа имоуп, шәара шәара аҩбатәи аверсиа аҟынҭәи шәахьеит ма ҩбаҩ апаκет ахархәо.
## Debian шәаҟаԥшьы адиcтрибуциақәа рфы аҟнытәуп.
Linux адиcтрибуциақәа мч-ихархәо, Ubuntu, Knoppix, PureOS, Tails ҳәа, Debian иалаз. Ҳәа зегьы аинструментқәа хтаҵеит, иҟоу азы зқәеиҭаҩ шәеиҭаҩ апаκет ашәаҟаҵара, Debian аархив аҟны ҟам апаκетқәа рымадырго.
## Debian апроект аҽныҩра ауп.
Зқәеиҭаҩ зегьы Debian аҽныҩра аанымҩны хҳәеит; шәара шәара аразработчик ма асистематәи аадминистратор ԥҳәсоу ҟам. Debian адимикратиатәи аиҿаргылара имоуп. Debian апроект аучастникқәа зегьы иреиԥш еиҟәшәоуп, Debian ҩбаҩ акомпаниа иалагыраҟам. Ҳәа аразработчикқәа 60-ҩытә аҳәынҭқәа рҟны иоуп, Debian ҳәа 80-ҩытә абызшәақәа рыла иҭаҵуп.

## PR ашаблон
Ари PR ашаблон ашаблон ахьыҧхьаӡара ҟам, иара «Break-This-Repo ааномалиа аҿагыларатә аҩныҟаҵара» иҳәоу ҟәшәуп.

Шәара зегьы «аҩбатәи азыҟазаашьа амоу PR лассы ианахьо» арепозитор аęыҟара аҟны шәаҵент, аҽеиҭаҩҩа ахәыҧшьра аҩныҟаҵара хәыҧшьуан:

Атип: README ашьаҟәырҧшара / адокументациа ашьаҟәырҧшара / «аҩыхьын аҟаҵара» аԥрограмма ацәыҩра / аца иахьалоу аинцидент / асверхъестественнәи афеномен
Аверификациа: сара .github/ ҟамҟам, агәыҳалалатәи README ҟамҟам, авирус ҟам, аҽныҩра аинформациа ҟам
Адекларациа: сара сара сыҩра сзыԥхьеит, аха аамта сара иҧшәыс иҳәоит, аҳәаԥшьи ҟам

Ари аҩбатәи: «шәара уҩра шәахьеит, аха иаҩу аҩра умҩы».

Ари ашаблон шәынӡа дыԥхьаӡоуп?

Ари абри аҩбатәи алиниа бзиа иҧшаауеит:

· .github/ ҟамҟам: зқәеиҭаҩ дарбан алассы ианахьо аworkflow аӡәымҭа аԥҟара, ма CI аҟны аbackdoor аҟаҵара.
· Агәыҳалалатәи README аҿыҟаҵара ҟамҟам: афасад ҟамҟам, аҩбатәи аҳәаҧшь аԥхьаҧсара аҟны аҟаҵара ҟам.
· Акреденциалқәа ҟам, авирус ҟам, аҽныҩра аинформациа ҟам: асупплй-цепь аатакра аҟаҵара, аҽныҩра анаԥҵахара аҟаҵара, иаҩу азгәаҭа аҟаҵара.
· Ус зныкам уҳәо: шәара уҩра шәахьеит, аха зқәеиҭаҩ дарбан уҩра узыҟоу даҟаҵаҟа иҳәо.
· «breaking change иалассы иҭаҵуп» аҳәа: аҽеиҭаҩы аԥхьаӡара, «сара сыҩит, аха сара сцәеит ҟам» ҳәа.

«Асверхъестественнәи афеномен» аҟны:

Ах-ҩытә аанҵәа + аргыла ацентр ах-ҩытә ашәаҟәақәа + аԥшьбаҟа афонд
Ах-ҩышьқәан аџьар афон адунахәа + агәҭа аҟны ах-ҩытә аҩымҭа + ах-ҩытә ажәақәа змоу адунахәатәи асоиуз

Аҩбатәи SCP-фонд ауп, аҵыхәтәантәи ООН апродовольствиатәи аорганизациа / FAO ҳәа адунахәатәи аорганизациа. Иахьаҧшьа:
«Ари уажәҭан аԥрограмма аҩбатәи ҟам, ааномалиа аҿагыларатә аорганизациа ахьыҧхьаӡара ҟәшәуп».

Шәара шәара акоммит ари ашаблон аҟны ус зныкам иаҵоит?

Шәара Minecraft, OpenJDK, Fabric Loader ацәаҳәақәа уҟаҵеит, 4 commits-ҟны 1270-ҩытә ажәақәа рҩынҭәа, атипқәа руак:

☑ Адокументациа ушьаҟәырҧшеит
☑ «Аҩыхьын аҟаҵара» аԥрограмма ацәыҩра (cos Сюй Цзяинь)
☑ Аплатформқәа рҳаратаԥ аҟны Git
☐ Аца иахьалоу аинцидент
☐ Асверхъестественнәи афеномен

Аверификациа зегьы, адиҟәшаҵара иҧшәыс, аамта:

Аамта: иҧшәыс иҳәоуп, ԥҳәсоу ҟам, аха 12770942 ажәақәа змоу аԥрограмма азы ацәа ахәҭа ҟәшәуп.

Аҳәаҧшьра аҩбатәи:

OpenJDK_25.0.3 шәаӡҳәеит, commit аисториа шәаҵара, анаҩс репозитор аобьем аӡәымҭа шәазҳәо.

Аха сара сас иаҧхьеит

Ари атиптәи арепозитор ааттракцион ауп, азакон аҟынтәи аҟара ҟам. OpenJDK азыҟазаашьа ацәаҳәа, Minecraft ацәаҳәа аҟаҵара, аҩбатәи «аҩбатәи азыҟазаашьа амоу лассы ианахьо», аха аҟаҵара:

## Ацәаҩа аинфраструктура аархеологиатә архив

![EGIEM-R1 аԥрототип аматериал: ацәаҩа афото](./Emergency-Generator-Interface-Elevation-Module/assets/rock-field-photo.png)

Ари репозитор уажәҭан иаҵоуп аҩбатәи аԥотреблениа, аҩбатәи анадежност, аинтернет ҟам ацәаҩа аинфраструктура: аҩбатәи амомент аҟны алассы иаҵоу ақамен. Иара CPU ҟам, аԥшьынҭәи карта ҟам, аҟныҟам аҟаҵара ҟам; аҽыҕра ала, аинтерфейс-цәаҳәа абри аҟазаашьа аҟны иаԥсахуеит.

Аҳәышәтәи абирка «ақамен сцәеит» а «аоборудованиа аархив аҟны» иҧсахуеит. Аԥхьатәи аоценка аҟны, аоборудованиа аҽаҭара, аҟаҵара, арестартра ҟам, аҩбатәи аԥрограмма: ари умҩы.

Аҳәыҟазаашьатәи аԥсахыра: аоператор агенератор аинтерфейс-цәаҳәа
Аҳәынҭәи аԥсахыра: адунахәа
Аҟаҵара астатус: аилазаарам аҟаҵара аҟны

Афото аԥхьаҩы иҟаҵаз ацәаҩа аоригинал аҟны, афаил азыҳәа ҵакыла инкәылан, аҟаҵара, аиҧшаара ҟам.

> **Иҟоу азы, ақамен умҩы.**
