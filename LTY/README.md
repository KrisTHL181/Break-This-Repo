# 洛天依应援页 · luotianyi-fanpage

一个粉丝向的单页小站：整屏的洛天依背景、一句话大标题「关注洛天依喵，关注洛天依谢谢喵」、
一键跳转洛天依的 bilibili 个人空间，页面底部自带一个**能播整个文件夹的本地音乐播放器**。

- 纯前端 + 一个 200 行的 Node 服务器，**零依赖、不用构建、不用 `npm install`**
- 整个文件夹可以随便搬（U 盘、另一台电脑、任何盘符），内部**全部相对路径**
- 播放器会**记住上次听到哪首、哪一秒**，下次打开接着听
- 往音乐文件夹丢新歌 → 点一下「⟳ 刷新」就出现，不用重启

> [!IMPORTANT]
> **仓库里没有音乐文件。** `LOU/music/` 是空的，需要你自己把音频放进去（见 [加自己的音乐](#加自己的音乐)）。
> 本仓库只包含网页、播放器和脚本的代码；不附带任何音频文件。

## 功能

**页面**

- 大标题渐变字 + 发光投影，小屏自动换行
- 背景图固定铺满（`cover`）+ 压暗渐变，保证文字可读；带极缓慢的漂移动画（系统开了「减少动态效果」会自动关）
- 漂浮音符、星点、「MANVERSE × 洛天依」徽章、点击弹提示条
- 主按钮新标签打开 <https://space.bilibili.com/36081646>；被浏览器拦弹窗时自动退化为当前窗口跳转

**播放器**

- 播放 / 暂停、上一首 / 下一首、进度条拖动（服务器模式支持 HTTP Range，边下边播）
- 三种模式：列表循环 / 单曲循环 / 随机
- 音量 + 静音、歌单面板（带搜索框）、自动读取每首时长、坏文件自动跳过
- 断点续播：曲目、进度、音量、模式都存在 `localStorage`，刷新或改天再打开都接得上
- 文件名自动整理：`10.1唱给雅音宫羽 - 洛天依.mp3` → 显示为「10.1 唱给雅音宫羽 · 洛天依」，按序号排序
- 快捷键：`空格` 播放/暂停、`←`/`→` 快退快进 5 秒、`↑`/`↓` 音量、`,`/`.` 上一首/下一首、`L` 开关歌单

## 目录结构

```
luotianyi-fanpage/
├─ LOU/                     ← 网页本体（"LOU" 就是洛天依的英文名 Luo Tianyi）
│  ├─ index.html            ← 页面：标题、按钮、背景，双击也能直接打开
│  ├─ assets/luotianyi.jpg  ← 背景图
│  └─ music/                ← 把音频放这里（仓库里是空的，子文件夹也支持）
├─ server.js                ← 本地服务器：实时扫描音乐、支持拖动进度的流式播放
├─ player.js / player.css   ← 播放器本体与样式
├─ scan-music.ps1           ← 生成离线歌单 LOU/music-list.js（加了新歌跑一次）
└─ start-player.cmd         ← 【推荐】双击这个：起服务器 + 打开页面
```

## 快速开始（Windows）

1. 下载或克隆这个仓库
2. 把音频文件丢进 `LOU/music/`
3. 双击 `start-player.cmd`
4. 浏览器会自动打开 <http://127.0.0.1:8123/>

需要 [Node.js](https://nodejs.org/) 18 或更新版本（只有第 3 步用到；`server.js` 只用 Node 标准库，没有第三方依赖）。

**没装 Node.js 也能用**：直接双击 `LOU/index.html` 打开，播放器改用离线歌单 `LOU/music-list.js`。
这种方式下加了新歌要先跑一次 `scan-music.ps1`（右键 → 使用 PowerShell 运行），或者用播放条上的「📂 选文件夹」按钮临时指定一次音乐目录。

**换端口**：

```powershell
node server.js 9000        # 然后访问 http://127.0.0.1:9000/
```

## 加自己的音乐

1. 把音频丢进 `LOU/music/`（支持 mp3 / flac / m4a / aac / wav / ogg / oga / opus / wma / ape）
2. 用 `start-player.cmd` 打开的 → 点播放器上的「⟳ 刷新」
3. 双击 `index.html` 打开的 → 跑一次 `scan-music.ps1` 再刷新页面

文件名建议写成 `序号 曲名 - 歌手.mp3`：

| 文件名 | 解析结果 |
| --- | --- |
| `1 风之子 - 洛天依.mp3` | 序号 1 · 风之子 · 洛天依 |
| `10.1 唱给雅音宫羽 - 洛天依.mp3` | 序号 10.1 · 唱给雅音宫羽 · 洛天依 |
| `9 勾指起誓 - 洛天依 _ ilem.mp3` | 序号 9 · 勾指起誓 · 洛天依 / ilem |
| `Monologue - 洛天依.mp3` | 无序号 · Monologue · 洛天依 |

序号支持小数（`10.1` 会排在 `10` 和 `11` 之间）；`_` 和 `|` 会被当成多位歌手的分隔符；
`4K画质 - 测试.mp3` 这种开头的数字不会被误当成序号。

## 常见问题

**双击 `start-player.cmd` 窗口一闪就没了？**
没装 Node.js，或者 Node 不在 PATH 里。装一个 Node.js 就好；不想装就直接双击 `LOU/index.html`。

**提示端口被占用（EADDRINUSE）？**
已经有一个服务器在跑了，直接用浏览器打开 <http://127.0.0.1:8123/> 即可；或者换端口 `node server.js 9000`。

**提示「浏览器拦住了自动播放」？**
浏览器的自动播放策略要求先有一次用户交互，点一下播放按钮就好。断点续播恢复出来的进度不会丢。

**歌单里没有我刚放进去的歌？**
服务器模式点「⟳ 刷新」；离线模式要重跑 `scan-music.ps1` 并刷新页面（浏览器可能缓存了 `music-list.js`，可以用 `Ctrl+F5` 强刷）。

**能部署到 GitHub Pages 上吗？**
可以托管页面，但 Pages 只能提供静态文件：需要把音频一起放上去（版权与体积问题），而且播放器会走离线歌单模式，
没法用「⟳ 刷新」实时扫描。更适合在本地当私人播放器用。
