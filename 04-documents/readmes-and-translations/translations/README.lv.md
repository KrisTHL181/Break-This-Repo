## Būvēšana no pirmkoda

Repozitorijā ir vairākas neatkarīgas būvēšanas ieejas. Instalē vajadzīgos rīkus un izpildi komandas no repozitorija saknes.

### C++ ar Make

Nepieciešams kompilators, kas atbalsta C++11:

```bash
make
```

Lai notīrītu būvēšanas artefaktus:

```bash
make clean
```

Pēc noklusējuma tiek ģenerēti `fozu` un `what`; operētājsistēmā Windows arī `beep_win`.

### C++ ar CMake

Nepieciešams CMake 3.16 vai jaunāks un C++ kompilators:

```bash
cmake -S . -B build/cmake
cmake --build build/cmake
```

### C++ ar Meson

Nepieciešami Meson, Ninja un C++ kompilators:

```bash
meson setup build/meson
meson compile -C build/meson
```

### Python un Rust ar maturin

Python paplašinājums tiek būvēts ar Rust un [maturin](https://www.maturin.rs/). Nepieciešama Rust rīku ķēde (ar `cargo`) un Python 3.13 vai jaunāks:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install maturin
```

Virtuālajā vidē izpildi vienu no šīm komandām:

```bash
# Kompilēt un instalēt pašreizējā virtuālajā vidē
maturin develop

# Būvēt izplatāmu wheel failu
maturin build --release
```

Wheel faili tiek ģenerēti `target/wheels/`. Rust paplašinājuma ieejas kods ir [`src/lib.rs`](src/lib.rs), un Python būvēšanas konfigurācija ir [`pyproject.toml`](pyproject.toml).

### TypeScript ar Hereby

TypeScript daļa atrodas `typescript/` un izmanto Node.js, npm un Hereby:

```bash
cd typescript
npm install
npm run build:compiler
```

Ja vēlies būvēt gan kompilatoru, gan testu mērķus, izpildi `npm run build`. Lai notīrītu būvēšanas artefaktus, vari izpildīt `npm run clean`.

## Pakotnes Linux distributīviem

Distributīvu pakotņu veidnes atrodas `debian/` un `packaging/`. Šīs pakotnes instalē C++ komandrindas programmas `fozu` un `what`; Python/Rust paplašinājumam joprojām izmanto iepriekš aprakstīto maturin procesu. Repozitorijs vēl nedeklarē vienotu atvērtā koda licenci, tāpēc pirms oficiālas izlaišanas pārbaudi un aizstāj licences lauku katrā pakotnes failā.

### Debian un Ubuntu

Nepieciešami `dpkg-buildpackage`, Debhelper, CMake un GCC:

```bash
sudo apt update
sudo apt install build-essential cmake debhelper devscripts
dpkg-buildpackage -us -uc
sudo apt install ../break-this-repo_0.0.0_$(dpkg --print-architecture).deb
```

Vari arī tieši instalēt jau kompilētu `.deb` failu:

```bash
sudo apt install ./break-this-repo_*.deb
```

### Arch Linux

Nepieciešami `base-devel`, CMake un GCC. Vispirms ģenerē no pirmkoda arhīvu, kas atbilst `PKGBUILD` versijai:

```bash
sudo pacman -S --needed base-devel cmake gcc
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o packaging/archlinux/break-this-repo-0.0.0.tar.gz HEAD
cd packaging/archlinux
makepkg -si
```

### Fedora

Nepieciešami RPM būvēšanas rīki, CMake un GCC:

```bash
sudo dnf install @development-tools cmake rpmdevtools
rpmdev-setuptree
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o ~/rpmbuild/SOURCES/break-this-repo-0.0.0.tar.gz HEAD
rpmbuild -ba packaging/fedora/break-this-repo.spec
sudo dnf install ~/rpmbuild/RPMS/$(uname -m)/break-this-repo-0.0.0-1.*.rpm
```

### Gentoo

Nokopē ebuild uz lokālu overlay un pēc tam ļauj Portage ģenerēt Manifest un instalēt:

```bash
sudo mkdir -p /var/db/repos/local/app-misc/break-this-repo
sudo cp packaging/gentoo/app-misc/break-this-repo/* \
	/var/db/repos/local/app-misc/break-this-repo/
cd /var/db/repos/local/app-misc/break-this-repo
sudo ebuild break-this-repo-0.0.0.ebuild manifest
sudo emerge --ask app-misc/break-this-repo
```

# Debian --vispārējas nozīmes operētājsistēma
[![Debian Logo](https://www.debian.org/Pics/openlogo-50.png)](https://www.debian.org/)
## Debian ir brīva programmatūra.
Debian sastāv no brīvas un atvērtā koda programmatūras un vienmēr paliks 100 % brīva. Ikviens ir brīvs to lietot, mainīt un izplatīt. Tas ir mūsu galvenais solījums lietotājiem. Tā ir arī bezmaksas.
## Debian ir stabila un droša.
Debian ir uz Linux balstīta operētājsistēma, ko izmanto visdažādākajās ierīcēs, no portatīvajiem datoriem līdz galddatoriem un serveriem. Mēs nodrošinām saprātīgas noklusējuma konfigurācijas katram pakotnei un regulārus drošības atjauninājumus visā pakotnes dzīves ciklā.
## Debian ir plašs aparatūras atbalsts.
Lielāko daļu aparatūras jau atbalsta Linux kodols. Tas nozīmē, ka arī Debian to atbalsta. Ja nepieciešams, var izmantot arī patentētus aparatūras draiverus.
## Debian piedāvā elastīgu instalētāju.
Lietotāji, kas vēlas izmēģināt Debian pirms instalēšanas, var izmantot mūsu Live CD. Tas satur arī Calamares instalētāju, kas padara Debian instalēšanu no tiešsaistes sistēmas ļoti vienkāršu. Pieredzējušāki lietotāji var izmantot Debian instalētāju, kas piedāvā vairāk precīzas regulēšanas iespēju, tostarp iespēju izmantot automatizētus tīkla instalēšanas rīkus.
## Debian piedāvā vienmērīgus atjauninājumus.
Operētājsistēmas uzturēšana aktuālā stāvoklī ir ļoti vienkārša, gan ja vēlies atjaunināt uz pilnīgi jaunu versiju, gan ja tikai vienu pakotni.
## Debian ir daudzu citu distributīvu pamats.
Daudzi ļoti populāri Linux distributīvi, piemēram, Ubuntu, Knoppix, PureOS un Tails, ir balstīti uz Debian. Mēs nodrošinām visus nepieciešamos rīkus, lai ikviens varētu izveidot savas pakotnes, kad tas ir nepieciešams, papildinot tās, kas nav Debian arhīvā.
## Debian projekts ir kopiena.
Ikviens var būt daļa no Debian kopienas; tev nav jābūt izstrādātājam vai sistēmu administratoram. Debian ir demokrātiska pārvaldības struktūra. Tā kā visiem Debian projekta dalībniekiem ir vienādas tiesības, Debian nevar kontrolēt viena atsevišķa kompānija. Mūsu izstrādātāji nāk no vairāk nekā 60 valstīm/reģioniem, un pats Debian ir tulkots vairāk nekā 80 valodās.

## PR veidne
Šo PR veidni vairs nevar īsti saukt par veidni; tai vajadzētu saukties «Break-This-Repo anomāliju aizturēšanas pieteikums».

Jūs esat paņēmuši repozitoriju, kas tikai «automātiski apvieno PR bez konfliktiem», un spēlējušies ar to tik ilgi, ka uzturētājs sāka rakstīt:

Tips: spēriens pa README / spēriens pa dokumentāciju / tukšas pilsētas koda kļūme / kaķa izraisīts incidents / pārdabisks fenomens
Pārbaude: es neaiztiku .github/, neaiztiku aizsargāto README, nav vīrusu, nav personiskas informācijas
Deklarācija: es atzīstu, ka salauzu, bet iemeslu izdomāju, un tas pat nav obligāts

Būtībā tas nozīmē: «tu drīksti trokšņot, bet ne īstu troksni».

No kā šī veidne aizsargā?

Tā faktiski novelk līniju ļoti skaidri:

· Neaiztikt .github/: neļauj kādam uzspridzināt pašu automātiskās apvienošanas darbplūsmu vai iebāzt aizmugures durvis CI.
· Neaiztikt aizsargātās README daļas: fasāde tomēr ir vajadzīga, nevar pārvērst sākumlapu kaut kādā dīvainībā.
· Nav akreditācijas datu, vīrusu vai personiskas informācijas: pret piegādes ķēdes uzbrukumiem, pret doksing, pret īstu ļaunprātību.
· Izskaidrot, kā novērot: tu drīksti izspēlēt triku, bet cilvēkiem jāzina, kā uz to skatīties.
· Paziņot «veiksmīgu breaking change»: pašironisks atbildības noliegums, tas ir, «es to izdarīju, bet esmu neatbildīgs».

Kas attiecas uz sēriju «pārdabisks fenomens»:

trīs burti + trīs bultas ap apli + iezīmēts fonds
pasaules karte pentagrammas fonā + apkārt kultūraugu gredzens + piecu vārdu starptautiska alianse

«Tā vairs nav koda problēma; mēs iesakām ziņot par anomāliju anomāliju aizturēšanas organizācijai.»

Kā tavs commit var iekļauties šajā veidnē?

Tu augšupielādē Minecraft, OpenJDK un Fabric Loader pirmkodu, 4 commitos iegūstot vairāk nekā 12,7 miljonus rindu; kā tipu vari atzīmēt:

Bet brīdinājums tomēr ir vietā

## Vietējās infrastruktūras arheoloģijas arhīvs

![EGIEM-R1, īstais prototips: foto no vietas](./Emergency-Generator-Interface-Elevation-Module/assets/rock-field-photo.png)

Dzeltenā etiķete ir tas, kas paaugstina «atradu akmeni» līdz «ierakstīts iekārtu reģistrā». Pēc sākotnējā novērtējuma šai ierīcei nav nepieciešama ne pieteikšanās, ne atjauninājumi, ne pārstartēšana; vienīgā zināmā apkopes darbība ir: neaiztiec to.
