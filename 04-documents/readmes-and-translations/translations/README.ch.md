## Build ginen i Source

I repositorio gågao varios na dåno' build independiente. Pot favor, inståla i herramienta maseha gi nekesidåd, ya bisi i komando gi raíz di repositorio.

### C++ yan Make

Necesita un kompiladót na umayuda i C++11:

```bash
make
```

Limpia i produkto di build:

```bash
make clean
```

Pära normal, umi-crea i `fozu` yan `what`; gi Windows umi-crea lokkue' i `beep_win`.

### C++ yan CMake

Necesita CMake 3.16 o mas briosu, yan un kompiladót di C++:

```bash
cmake -S . -B build/cmake
cmake --build build/cmake
```

### C++ yan Meson

Necesita Meson, Ninja, yan un kompiladót di C++:

```bash
meson setup build/meson
meson compile -C build/meson
```

### Python yan Rust yan maturin

Python extension ginen Rust yan [maturin](https://www.maturin.rs/). Necesita i toolchain di Rust (gågao `cargo`) yan Python 3.13 o mas briosu:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install maturin
```

Bisi i unu gi este na mangga' na komando gi ambiente virtual:

```bash
# Compile yan inståla gi i ambiente virtual presente
maturin develop

# Build i wheel file ni siña distribui
maturin build --release
```

I produkto di build di wheel gaige gi `target/wheels/`. I kodigu di entrada di extension Rust gaige gi [`src/lib.rs`](src/lib.rs), ya i konfigurasion di build di Python gaige gi [`pyproject.toml`](pyproject.toml).

### TypeScript yan Hereby

I pottion di TypeScript gaige gi `typescript/`, umi-usa i Node.js, npm, yan Hereby:

```bash
cd typescript
npm install
npm run build:compiler
```

Si necesita un build i kompiladót yan i meta di test såbåbå, bisi `npm run build`. Para limpia i produkto di build, siña bisi `npm run clean`.

## Paketes di Distribusion Linux

I plantilla di packaging di distribusion gaige gi `debian/` yan `packaging/`. Este na paketes umi-inståla i program di command-line di C++ na `fozu` yan `what`; i extension di Python/Rust debe uusa lokkue' i prosedimientu maturin na gaige åttes. I repositorio, gi presente, ti umi-deklåra un lisensia open-source unida, pära i publikåtion ofisiat, por favor konfirma ya remplasa i kampo di lisensia gi kada file di packaging.

### Debian yan Ubuntu

Necesita `dpkg-buildpackage`, Debhelper, CMake, yan GCC:

```bash
sudo apt update
sudo apt install build-essential cmake debhelper devscripts
dpkg-buildpackage -us -uc
sudo apt install ../break-this-repo_0.0.0_$(dpkg --print-architecture).deb
```

Siña lokkue' inståla direktamente i file `.deb` ni binibuild:

```bash
sudo apt install ./break-this-repo_*.deb
```

### Arch Linux

Necesita `base-devel`, CMake, yan GCC. Primero, crea un archive ginen i source ni maseha yan i bettin di `PKGBUILD`:

```bash
sudo pacman -S --needed base-devel cmake gcc
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o packaging/archlinux/break-this-repo-0.0.0.tar.gz HEAD
cd packaging/archlinux
makepkg -si
```

### Fedora

Necesita i herramienta di build di RPM, CMake, yan GCC:

```bash
sudo dnf install @development-tools cmake rpmdevtools
rpmdev-setuptree
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o ~/rpmbuild/SOURCES/break-this-repo-0.0.0.tar.gz HEAD
rpmbuild -ba packaging/fedora/break-this-repo.spec
sudo dnf install ~/rpmbuild/RPMS/$(uname -m)/break-this-repo-0.0.0-1.*.rpm
```

### Gentoo

Kopia i ebuild para i overlay lokal, despues manda i Portage umi-crea i Manifest yan inståla:

```bash
sudo mkdir -p /var/db/repos/local/app-misc/break-this-repo
sudo cp packaging/gentoo/app-misc/break-this-repo/* \
	/var/db/repos/local/app-misc/break-this-repo/
cd /var/db/repos/local/app-misc/break-this-repo
sudo ebuild break-this-repo-0.0.0.ebuild manifest
sudo emerge --ask app-misc/break-this-repo
```

# Debian --Sistemas Operatibo General
[![Debian Logo](https://www.debian.org/Pics/openlogo-50.png)](https://www.debian.org/)
## Debian ese un softwåre liberåo.
Debian ginen softwåre liberåo yan open-source, ya ufan-permana 100% liberåo. Cada taotao siña umi-usa, modifica, yan distribui libre. Este i prinsipåt na promesa-nami para i cliente. Yan gratis lokkue'.
## Debian estable yan siguru.
Debian este un sistemas operatibo Linux na umi-usa gi maskada klåsi na ekipu, ginen i laptop, desktop, yan server. Ufan-otga i defet na configuration para cada pakete, ya i atualisasion siguru regular durante i vida di pakete.
## Debian gågao i ayudu bibrås di hardware.
I mayoråt di hardware esta umi-ayuda ginen i Linux kernel. Poreke, Debian lokkue' umi-ayuda siha. Si necesita, siña umi-usa lokkue' i driver hardware proprietary.
## Debian umenta i instaladót flexible.
Para i mangge' ni malago' puebła Debian antes di inståla, siña umi-usa i Live CD-hu. Gågao lokkue' i instaladót Calamares, ya mâfåsil i inståla Debian ginen i sitema Live. I mangge' yan mas eksperiensia siña umi-usa i instaladót Debian, ni umi-otga mas na opsyon para i fine-tuning, inkluye i herramienta di instalasion network automatika.
## Debian umenta i atualisasion suåbe.
Mantiene i sistemas operatibo atual esta gosi mâfåsil, ya un malago' umi-upgrade para un bentana nuevo lokkue', o simplemente umi-upgrade un pakete solu.
## Debian ese i fondo di meggai na otron distribusion siha.
Mechuda na distribusion Linux popular, pära huentos i Ubuntu, Knoppix, PureOS, yan Tails, ginen Debian. Ufan-otga todo i herramienta necesita, pära kada taotao si necesita siña umi-crea i propio pakete-niha, para suplementa i pakete ni ti gaige gi achivo di Debian.
## Debian ese un komunidåt.
Cada taotao siña maseha un miembro di komunidåt Debian; ti necesita un developer o administradót di sistemas. Debian gågao un gobietnu demokratiko. Sa' todos i miembro di proyekto Debian gågao i derechu igual, Debian ti siña maseha mânda gi un kompanía solu. I developer-hu ginen mas di 60 na pais, yan Debian lokkue' ya esta matratdu gi mas di 80 na lengguåhi.
