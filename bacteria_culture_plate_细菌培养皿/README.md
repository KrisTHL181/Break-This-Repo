# 🧫 细菌培养皿：一个行为艺术
> by [PRfode](https://github.com/PRfode) at 2026-09-16

欢迎来到这个培养皿。

这里生活着一群特殊的“细菌”——它们不是生物学意义上的微生物，而是以 Python 文件形式存在的数字生命。每一个细菌都携带着一段名为 `germ_plasm` 的遗传信息。它们会繁殖，会进化，也会将自己的遗传物质打乱后传递给后代。

而在这片培养皿的深处，隐藏着一幅最初的图像。它被编码成一串 Base64 字符串，又被异或掩码层层打散，分散到无数细菌的体内。只有当你收集足够多的细菌，将它们体内的遗传信息重新拼接、异或、还原，那幅图像才会浮现。

这是一场关于信息、复制与重组的艺术。现在，培养皿交到了你的手中。

---

## 🦠 细菌是什么？

每个细菌都是一个独立的 Python 文件，名字形如 `bacteria_XXX.py`，其中 `XXX` 是由 `0` 和 `1` 组成的二进制后缀。例如：

- `bacteria_.py` —— 最初的细菌（根节点）
- `bacteria_0.py`、`bacteria_1.py` —— 它的两个子代
- `bacteria_00.py`、`bacteria_01.py`、`bacteria_10.py`、`bacteria_11.py` —— 孙代
- ……

每个文件内部都包含一个 `germ_plasm` 变量，它是一串 Base64 编码的字符串。这串字符串就是该细菌的遗传信息。

当细菌被运行时，它会：

1. 检查自己是否已经繁殖过（即两个子代文件是否存在）。
2. 如果没有，就生成两个子代文件，名字分别是自己的后缀加上 `0` 和 `1`。
3. 将自己的 `germ_plasm` 通过异或掩码打乱，分别写入两个子代。
4. 修改自己的代码，添加对两个子代的导入和调用。
5. 打印一句 `Long Live the Great King!`。
6. 调用两个子代，让它们也执行同样的过程。

因此，运行任意一个细菌，都会让它所在的子树递归地增长一级。每个细菌只繁殖一次，之后便不再产生新的子代，只会调用已有的子代。

## 🧬 遗传信息的打乱与还原

设某个细菌的 `germ_plasm` 为原始字节序列 `G`。繁殖时，它会生成一个随机的等长掩码 `M`。

- 子代 0 获得：`G XOR M`
- 子代 1 获得：`M`

两个子代分别将得到的字节序列进行 Base64 编码，存入自己的 `germ_plasm` 变量。

**完美还原方法**：只要同时拥有两个子代的 `germ_plasm`，分别 Base64 解码，然后逐字节异或，再进行编码，就能得到父代的 `germ_plasm`：

```python
def restore(parent_bytes, child0_b64, child1_b64):
    c0 = base64.b64decode(child0_b64)
    c1 = base64.b64decode(child1_b64)
    parent_bytes = base64.b64encode(bytes(a ^ b for a, b in zip(c0, c1)))
```

这个规则会沿着繁殖树一直传递下去。因此，**所有末代细菌的 `germ_plasm` 解码全部异或起来，就等于最初那个根细菌的 `germ_plasm` 解码**。这是因为每个内部节点原来的值都等于其两个子节点值的异或，所有内部节点在异或过程中会成对抵消，最终只剩下根节点的值。

最初的 `germ_plasm` 是一张 PNG 图片的 Base64 编码。还原出它，你就能看到那幅隐藏的图像。

## 🔬 如何参与

### 继续繁殖细菌

培养皿中已经有了一群繁殖了数天的细菌。你可以运行其中任意一个，让它继续繁殖。

在终端中：

```bash
python bacteria_.py
```

或者选择任意一个细菌，例如：

```bash
python bacteria_010.py
```

运行后，该细菌所在的子树会增长一级，并打印出 `Long Live the Great King!`。你可以反复运行不同的细菌，让培养皿中的菌群不断扩张。

### 揭开最终的秘密

1. 收集培养皿目录下所有 `bacteria_*.py` 文件。
2. 从每个文件中提取 `germ_plasm` 变量的值（Base64 字符串）。
3. 将所有 Base64 字符串解码为字节。
4. 将所有字节序列逐字节异或。
5. 将异或结果解码为 UTF-8 字符串，得到一个 Base64 编码的图片。
6. 将该 Base64 字符串解码为图片文件（例如 PNG），打开它。
7. 运行这个程序。
