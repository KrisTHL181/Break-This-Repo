## Изградња из изворног кода

Репозиторијум садржи неколико независних улазних тачака за изградњу. Инсталирај потребне алате и покрени команде из корена репозиторијума.

### C++ са Make-ом

Потребан ти је компајлер који подржава C++11:

```bash
make
```

За чишћење артефаката изградње:

```bash
make clean
```

Подразумевано се генеришу `fozu` и `what`; на Windows-у и `beep_win`.

### C++ са CMake-ом

Потребан ти је CMake 3.16 или новији и C++ компајлер:

```bash
cmake -S . -B build/cmake
cmake --build build/cmake
```

### C++ са Meson-ом

Потребни су ти Meson, Ninja и C++ компајлер:

```bash
meson setup build/meson
meson compile -C build/meson
```

### Python и Rust са maturin-ом

Python екстензија се гради помоћу Rust-а и [maturin-а](https://www.maturin.rs/). Потребан ти је Rust алатни ланац (са `cargo`) и Python 3.13 или новији:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install maturin
```

У виртуелном окружењу покрени једну од ових команди:

```bash
# Компајлирај и инсталирај у тренутно виртуелно окружење
maturin develop

# Изгради дистрибуирајућу wheel датотеку
maturin build --release
```

Wheel-ови се генеришу у `target/wheels/`. Улазни код Rust екстензије је у [`src/lib.rs`](src/lib.rs), а конфигурација изградње Python-а у [`pyproject.toml`](pyproject.toml).

### TypeScript са Hereby-ом

TypeScript део је у `typescript/` и користи Node.js, npm и Hereby:

```bash
cd typescript
npm install
npm run build:compiler
```

Ако желиш да изградиш и компајлер и тест циљеве, покрени `npm run build`. За чишћење артефаката изградње можеш покренути `npm run clean`.

## Пакети за Linux дистрибуције

Шаблони паковања за дистрибуције су у `debian/` и `packaging/`. Ови пакети инсталирају C++ програме командне линије `fozu` и `what`; за Python/Rust екстензију и даље користи горе описани maturin поступак. Репозиторијум још не декларише јединствену лиценцу отвореног кода, па пре званичног издања провери и замени поље лиценце у свакој датотеци паковања.

### Debian и Ubuntu

Потребни су ти `dpkg-buildpackage`, Debhelper, CMake и GCC:

```bash
sudo apt update
sudo apt install build-essential cmake debhelper devscripts
dpkg-buildpackage -us -uc
sudo apt install ../break-this-repo_0.0.0_$(dpkg --print-architecture).deb
```

Можеш и директно инсталирати већ изграђену `.deb` датотеку:

```bash
sudo apt install ./break-this-repo_*.deb
```

### Arch Linux

Потребни су ти `base-devel`, CMake и GCC. Прво генериши из изворног кода архиву која одговара верзији у `PKGBUILD`-у:

```bash
sudo pacman -S --needed base-devel cmake gcc
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o packaging/archlinux/break-this-repo-0.0.0.tar.gz HEAD
cd packaging/archlinux
makepkg -si
```

### Fedora

Потребни су ти алати за изградњу RPM-а, CMake и GCC:

```bash
sudo dnf install @development-tools cmake rpmdevtools
rpmdev-setuptree
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o ~/rpmbuild/SOURCES/break-this-repo-0.0.0.tar.gz HEAD
rpmbuild -ba packaging/fedora/break-this-repo.spec
sudo dnf install ~/rpmbuild/RPMS/$(uname -m)/break-this-repo-0.0.0-1.*.rpm
```

### Gentoo

Копирај ebuild у локални overlay и затим пусти Portage да генерише Manifest и инсталира:

```bash
sudo mkdir -p /var/db/repos/local/app-misc/break-this-repo
sudo cp packaging/gentoo/app-misc/break-this-repo/* \
	/var/db/repos/local/app-misc/break-this-repo/
cd /var/db/repos/local/app-misc/break-this-repo
sudo ebuild break-this-repo-0.0.0.ebuild manifest
sudo emerge --ask app-misc/break-this-repo
```

# Debian --универзални оперативни систем
[![Debian Logo](https://www.debian.org/Pics/openlogo-50.png)](https://www.debian.org/)
## Debian је слободан софтвер.
Debian се састоји од слободног софтвера отвореног кода и увек ће остати 100 % слободан. Свако може слободно да га користи, мења и дистрибуира. То је наше главно обећање нашим корисницима. Такође је бесплатан.
## Debian је стабилан и сигуран.
Debian је оперативни систем заснован на Linux-у, који се користи на најразличитијим уређајима, од преносних рачунара до стоних рачунара и сервера. За сваки пакет пружамо разумне подразумеване конфигурације и редовна безбедносна ажурирања кроз цео животни циклус пакета.
## Debian има широку подршку за хардвер.
Већину хардвера већ подржава Linux језгро. То значи да га подржава и Debian. Ако је потребно, могу се користити и власнички хардверски драјвери.
## Debian нуди флексибилан инсталациони програм.
Корисници који желе да испробају Debian пре инсталације могу да користе наш Live CD. Садржи и инсталациони програм Calamares, што инсталацију Debian-а са живог система чини врло једноставном. Искуснији корисници могу да користе Debian-ов инсталациони програм, који нуди више могућности за фино подешавање, укључујући могућност коришћења алата за аутоматизовану мрежну инсталацију.
## Debian нуди глатка ажурирања.
Одржавање оперативног система ажурним врло је једноставно, било да желиш да надоградиш на потпуно ново издање или да ажурираш само један пакет.
## Debian је основа многих других дистрибуција.
Многе врло популарне Linux дистрибуције, попут Ubuntu-а, Knoppix-а, PureOS-а и Tails-а, засноване су на Debian-у. Пружамо све потребне алате како би свако могао да изради сопствене пакете кад му затребају, да допуни оне којих нема у Debian-овом архиву.
## Debian пројекат је заједница.
Свако може бити део Debian-ове заједнице; не мораш бити програмер ни системски администратор. Debian има демократску структуру управљања. Будући да сви чланови Debian пројекта имају једнака права, Debian не може контролисати једна компанија. Наши програмери долазе из више од 60 земаља/региона, а сам Debian преведен је на више од 80 језика.

## Шаблон PR-а
Овај шаблон PR-а више се не може баш називати шаблоном; требало би да се зове «Захтев за задржавање аномалије за Break-This-Repo».

Ви сте узели репозиторијум који само «аутоматски спаја PR-ове без конфликата» и играли се с њим толико дуго да је одржавалац почео да пише:

Тип: ударац у README / ударац у документацију / квар кода празног града / инцидент који је изазвао мачак / натприродна појава
Провера: нисам дирао .github/, нисам дирао заштићени README, нема вируса, нема личних података
Изјава: признајем да сам то разбио, али разлог сам измислио, и није чак ни обавезан

У суштини то значи: «можеш да правиш неред, али не прави неред».

Од чега штити овај шаблон?

Заправо повлачи границу врло јасно:

· Не дирати .github/: спречава да неко разнесе сам ток аутоматског спајања или убаци задња врата у CI.
· Не дирати заштићене делове README-а: фасада је још увек потребна, не можеш насловну страну да претвориш у нешто чудно.
· Нема акредитива, вируса ни личних података: против напада на добављачки ланац, против доксинга, против праве злонамерности.
· Објаснити како посматрати: можеш да изведеш трик, али људи морају да знају како да га гледају.
· Изјавити «успешан breaking change»: самоиронично одрицање одговорности, односно «учинио сам то, али нисам одговоран».

Што се тиче серије «натприродна појава»:

три слова + три стрелице око круга + оцртана фондација
карта света на позадини пентаграма + око ње прстен усева + међународни савез од пет речи
