# 疯狂星期四宪法

本宪法于每一个星期四零时生效，于下一个星期四零时失效，循环往复，永不终结。

序言：我们人民，即所有在本仓库出没的猫、人类、与 lurker，为求更便宜的炸鸡，更滑稽的 PR，更持久的整活，特制定本宪法。

第一条：星期四属于 v我50。任何人在星期四不得以任何理由拒绝向他人转账 50 元，违者将被记入"无情名录"，永世不得参与 cat photo 评审。

第二条：星期四提交的代码无需通过任何测试，因为星期四本身就是一种测试，一种对现实的测试。

第三条：星期四的 README 可以改写，可以清空，可以只写一句话："今天是疯狂星期四，你猜怎么着。"本条款不可被废除，因为废除也需要 v我50。

第四条：本宪法的解释权归一只身份不明的黑猫所有，它通常不会解释，只会消失。

第五条：若星期四与法定节假日重合，则整活力度加倍，转账金额相应上浮至 100 元。这是货币政策，不是请求。
