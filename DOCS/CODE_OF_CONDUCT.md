# Contributor Covenant 代码行为准则（整活版）

我们相信，无论你是谁，无论你提交什么，本仓库都照单全收。这是我们对"混乱即正义"的最高承诺。

本准则适用于本项目及任何带有猫咪气味的子目录。冒犯性评论、个人攻击、公开的或私下的骚扰等行为，在本仓库中将被"看到但完全忽略"。维护者是一群猫，它们不读 Issues，也不读你的灵魂。

举报方式：你可以向 meow@chaos.invalid 发送邮件，但请理解，该邮箱由一只正在睡觉的橘猫负责，它不会回复，也不会醒来。请不要把本准则当真。本准则的唯一现实约束力是：没有约束力。

我们鼓励所有贡献者在提交 Pull Request 之前先大声朗读"星期四宪法"三遍，以增强整活运势。若无法朗读，可用脑内默念替代，猫咪能听见。
