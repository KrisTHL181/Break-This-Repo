# 混乱行为准则（Code of Chaos）

本文件优先级高于 CODE_OF_CONDUCT.md，当两者冲突时，以"更像猫的行为"为准。

第一条：任何 Pull Request 都不得被拒绝，除非它试图删除猫咪相关内容。删除猫 = 立即封禁（由猫亲自执行）。

第二条：嵌套文件夹深度不受限制。我们鼓励贡献者创建 `src/of/the/void/that/contains/only/a/single/cat/photo/` 这样的目录结构，以彰显存在主义式的工程美学。

第三条：所有 Bug 都是 Feature，所有 Feature 都是 Bug。任何试图区分二者的行为均视为 heresy（异端），将被判处在一台只装了 Brainfuck 解释器的机器上重构本 README。

第四条：每周四为法定整活日。当天的提交信息可全部替换为"疯狂星期四，v我50"。CI 会在周四自动跳过大门，并播放一段无声的 rickroll。

第五条：本准则本身也是混乱的一部分，可被任意 Pull Request 修改，无需理由，无需评审，无需清醒。
