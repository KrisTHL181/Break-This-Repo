# 键盘权法案

键盘是自由的最高象征。本法案保障所有 contributor 对键盘的神圣使用权，以及对无意义快捷键组合的探索权。

第一条：任何人不得因在代码里按下 `Ctrl+Z` 超过一万次而被嘲笑。撤销是思考的一种形式，尽管是倒退的思考。

第二条：机械键盘的噪音受本法案保护，列为"整活环境音"。邻居的投诉将被自动归档到 `/dev/null` 的平行宇宙副本中。

第三条：键盘上的 `F5` 键享有刷新一切（包括人生）的象征性权利，尽管实际上它只能刷新浏览器，且常常刷新到 rickroll 页面。

第四条：盲打者拥有在黑暗中敲击出完整 Brainfuck 程序的权利，该程序无需运行，其存在即为艺术。

第五条：本法案的最终解释权归那把已经掉了三个键帽、却依然被每日使用的古董键盘所有。它不说话，但每次按下回车都发出一声疲惫而满足的叹息。
