## Bouwe fanôf de boarnekoade

De repo befettet ferskate ûnôfhinklike bou-yngeappen. Ynstallearje it nedige ark en fierskôf de opdrachten fanôf de woartel fan 'e repo.

### C++ mei Make

Do hast in kompilearder nedich dy't C++11 stipet:

```bash
make
```

Om de bou-artefakten skjin te meitsjen:

```bash
make clean
```

Standert wurde `fozu` en `what` generearre; op Windows ek `beep_win`.

### C++ mei CMake

Do hast CMake 3.16 of nijer nedich, plus in C++-kompilearder:

```bash
cmake -S . -B build/cmake
cmake --build build/cmake
```

### C++ mei Meson

Do hast Meson, Ninja en in C++-kompilearder nedich:

```bash
meson setup build/meson
meson compile -C build/meson
```

### Python en Rust mei maturin

De Python-útwreiding wurdt boud mei Rust en [maturin](https://www.maturin.rs/). Do hast in Rust-arkketen (mei `cargo`) en Python 3.13 of nijer nedich:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install maturin
```

Fierskôf ien fan dizze opdrachten yn 'e firtuele omjouwing:

```bash
# Kompilearje en ynstallearje yn 'e hjoeddeiske firtuele omjouwing
maturin develop

# Bou in distribuearber wheel-bestân
maturin build --release
```

Wheels wurde generearre yn `target/wheels/`. De yngongskoade fan 'e Rust-útwreiding is yn [`src/lib.rs`](src/lib.rs), en de Python-boukonfiguraasje yn [`pyproject.toml`](pyproject.toml).

### TypeScript mei Hereby

It TypeScript-diel is yn `typescript/` en brûkt Node.js, npm en Hereby:

```bash
cd typescript
npm install
npm run build:compiler
```

As do sawol de kompilearder as de testdoelen bouwe wolst, fierskôf dan `npm run build`. Om bou-artefakten skjin te meitsjen kinst do `npm run clean` fierskôfje.

## Pakketten foar Linux-distribúsjes

De ferpakkingstemplates foar distribúsjes binne yn `debian/` en `packaging/`. Dizze pakketten ynstallearje de C++-kommandorigelprogramma's `fozu` en `what`; foar de Python/Rust-útwreiding, brûk noch altyd it maturin-proses hjirboppe. De repo ferklearret noch gjin ienriedige iepen-boarne-lisinsje, dus befestigje en ferfange it lisinsjefjild yn elk ferpakkingsbestân foar in offisjele útjefte.

### Debian en Ubuntu

Do hast `dpkg-buildpackage`, Debhelper, CMake en GCC nedich:

```bash
sudo apt update
sudo apt install build-essential cmake debhelper devscripts
dpkg-buildpackage -us -uc
sudo apt install ../break-this-repo_0.0.0_$(dpkg --print-architecture).deb
```

Do kinst ek in al boud `.deb`-bestân direkt ynstallearje:

```bash
sudo apt install ./break-this-repo_*.deb
```

### Arch Linux

Do hast `base-devel`, CMake en GCC nedich. Generearje earst in argyf fanôf de boarnekoade dat by de `PKGBUILD`-ferzje past:

```bash
sudo pacman -S --needed base-devel cmake gcc
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o packaging/archlinux/break-this-repo-0.0.0.tar.gz HEAD
cd packaging/archlinux
makepkg -si
```

### Fedora

Do hast RPM-bouark, CMake en GCC nedich:

```bash
sudo dnf install @development-tools cmake rpmdevtools
rpmdev-setuptree
git archive --format=tar.gz --prefix=break-this-repo-0.0.0/ \
	-o ~/rpmbuild/SOURCES/break-this-repo-0.0.0.tar.gz HEAD
rpmbuild -ba packaging/fedora/break-this-repo.spec
sudo dnf install ~/rpmbuild/RPMS/$(uname -m)/break-this-repo-0.0.0-1.*.rpm
```

### Gentoo

Kopiearje de ebuild nei in lokale overlay, en lit Portage dan it Manifest generearje en ynstallearje:

```bash
sudo mkdir -p /var/db/repos/local/app-misc/break-this-repo
sudo cp packaging/gentoo/app-misc/break-this-repo/* \
	/var/db/repos/local/app-misc/break-this-repo/
cd /var/db/repos/local/app-misc/break-this-repo
sudo ebuild break-this-repo-0.0.0.ebuild manifest
sudo emerge --ask app-misc/break-this-repo
```

# Debian --in algemien bestjoeringssysteem
[![Debian Logo](https://www.debian.org/Pics/openlogo-50.png)](https://www.debian.org/)
## Debian is frije software.
Debian bestiet út frije en iepen-boarne-software en sil altyd 100% frij bliuwe. Elkenien is frij om it te brûken, te feroarjen en te fersprieden. Dat is ús wichtichste tasizzing oan ús brûkers. It is ek fergees.
## Debian is stabyl en feilich.
Debian is in op Linux basearre bestjoeringssysteem dat op allerhanne apparaten brûkt wurdt, fan laptops oant burokompjûters en tsjinners. Wy leverje ferstannige standertkonfiguraasjes foar elk pakket en regelmjittige feiligensfernijings yn 'e hiele libbenssyklus fan in pakket.
## Debian hat brede hardwarestipe.
It measte fan 'e hardware wurdt al stipe troch de Linux-kearn. Dat betsjut dat Debian it ek stipet. As it nedich is, kinne ek propriêtêre hardwaredriuwers brûkt wurde.
## Debian biedt in fleksibele ynstallearder.
Brûkers dy't Debian probearje wolle foardat se it ynstallearje, kinne ús Live CD brûke. Dy befettet ek de Calamares-ynstallearder, wat it hiel maklik makket om Debian fanôf in live-systeem te ynstallearjen. Mear betûfte brûkers kinne de Debian-ynstallearder brûke, dy't mear opsjes biedt om fyn ôf te stellen, ynklusyf de mooglikheid om automatisearre netwurkynstallaasje-ark te brûken.
## Debian biedt soepele fernijings.
It is hiel maklik om dyn bestjoeringssysteem by de tiid te hâlden, of do no nei in folslein nije ferzje opwurdearje wolst of gewoan ien inkeld pakket bywurkje wolst.
## Debian is de basis fan in protte oare distribúsjes.
In protte tige populêre Linux-distribúsjes, lykas Ubuntu, Knoppix, PureOS en Tails, binne basearre op Debian. Wy leverje al it nedige ark sadat elkenien syn eigen pakketten meitsje kin as dat nedich is, om dy oan te foljen dy't net yn it Debian-argyf steane.
## It Debian-projekt is in mienskip.
Elkenien kin diel útmeitsje fan 'e Debian-mienskip; do hoechst gjin ûntwikkeler of systeembehearder te wêzen. Debian hat in demokratyske bestjoersstruktuer. Om't alle leden fan it Debian-projekt gelikense rjochten hawwe, kin Debian net troch ien bedriuw beheard wurde. Us ûntwikkelers komme út mear as 60 lannen/regio's, en Debian sels is oerset yn mear as 80 talen.

## PR-template
Dit PR-template kin net mear echt in template neamd wurde; it soe «Oanfraach om anomaaly-ynsluting foar Break-This-Repo» hjitte moatte.

Jimme hawwe in repo dat allinne «pull requests sûnder konflikten automatysk gearfoeget» sa lang spile dat de ûnderhâlder begûn te skriuwen:

Type: skop tsjin README / skop tsjin dokumintaasje / leech-stêd-koadeflater / foarfal feroarsake troch in kat / boppenatuerlik ferskynsel
Ferifikaasje: ik haw .github/ net oanrekke, de beskerme README net oanrekke, gjin virus, gjin persoanlike ynformaasje
Ferklearring: ik jou ta dat ik it brutsen haw, mar de reden haw ik betocht, en dy is net iens ferplichte

Koartsein: «do meist lawaai meitsje, mar gjin echte lawaai».

Wêrfoar beskermet dit template?

It lûkt de ûnderste line eins hiel dúdlik:

· Rekke .github/ net oan: foarkomt dat immen de automatyske gearfoegingswurkstream sels opblaast, of in efterdoar yn 'e CI set.
· Rekke de beskerme dielen fan 'e README net oan: in fasade is noch altyd nedich, do kinst de foarside net yn wat frjemds feroarje.
· Gjin oanmeldgegevens, firussen of persoanlike ynformaasje: tsjin oanfallen op 'e leveringsketen, tsjin doxxing, tsjin echte kweawilligens.
· Utlizze hoe't men it observearret: do meist in nûmer dwaan, mar minsken moatte witte hoe't se dernei sjogge.
· Ferklearje «suksesfolle breaking change»: in selsbespotlike ôfwizing fan ferantwurdlikheid, oftewol «ik haw it dien, mar ik bin net ferantwurdlik».

Wat de rige «boppenatuerlik ferskynsel» oanbelanget:

trije letters + trije pylken om in sirkel + in stifting mei bûtenline
in wrâldkaart op in pentagram-eftergrûn + in ring gewaaksen deromhinne + in ynternasjonale alliânsje fan fiif wurden

De earste is de SCP-stifting; de twadde is wierskynlik in ynternasjonale organisaasje lykas de FAO / de Fiedings- en Lânbou-organisaasje fan 'e Feriene Naasjes. Oerset betsjut it:
«Dit is net mear in koade-probleem; wy riede oan om de anomaaly by in anomaaly-ynslutingsorganisaasje te melden.»

Hoe kin dyn commit by dit template ynpasje?

Do lêst de boarnekoade fan Minecraft, OpenJDK en Fabric Loader op, en rispest mear as 12,7 miljoen rigels yn 4 commits; by type kinst do oantekening meitsje:

☑ skop tsjin de dokumintaasje
☑ leech-stêd-koadeflater (cosplay fan Xu Jiayin)
☑ Git oer platfoarms
☐ foarfal feroarsake troch in kat
☐ boppenatuerlik ferskynsel

Do meitsest oantekening by alle ferifikaasjes, kopiearrest de ferklearring, en as reden skriuwst do:

Reden: betocht, net ferplichte, mar 12.770.942 rigels koade fertsjinje dochs in titel.

Hoe't men it observearret:

Iepenje OpenJDK_25.0.3, sjoch nei de commit-skiednis, en fiel dan de stilte fan 'e grutte fan 'e repo.

Mar in warskôging is noch altyd passe

Dit soarte repo is in boarterstún, gjin wetteleas gebiet. It opladen fan 'e folsleine OpenJDK-boarnekoade of dy fan Minecraft jout miskien allinne in «konfliktfrij automatysk gearfoegjen», mar bringt mei:

· de grutte fan 'e repo ûntploft, en GitHub kin beheine of warskôgje;
· auteursrjocht-/lisinsjeproblemen: net alle boarnekoade kin samar earne yn smiten wurde;
· as immen dizze repo as ôfhinklikheid brûkt, is it in ramp yn 'e leveringsketen.

Dus de konklúzje is:
dit PR-template is it balânspunt dat de ûnderhâlder fûn hat tusken «iepenlike ferneatiging» en «in echte ûntploffing foarkomme».
Jimme meie trochspylje, mar it is it bêste om it as performance-keunst te behanneljen, net as in koade-repo. De SCP-stifting hat it rapport al ûntfongen.

## Argeologysk argyf fan 'e ynfrastruktuer op it plak

![EGIEM-R1, it echte prototype: foto op it plak](./Emergency-Generator-Interface-Elevation-Module/assets/rock-field-photo.png)

Dizze repo húsfêstiget no in stik ynfrastruktuer op it plak mei leech ferbrûk, hege betrouberens en hielendal offline: in stien dy't op in krityk momint tydlik oproppen waard. Hy hat gjin CPU, gjin netwurkkaart en gjin plannen om ûntslach te nimmen; allinne mei syn eigen gewicht hâldt er de ynterfacekast stevich op it krekte plak.

It giele label is wat «ik haw in stien oppakt» opwurdearret nei «ynskreaun yn it apparateregister». Nei in foarriedige beoardieling hat dit apparaat gjin oanmelding, fernijings of werstarts nedich; de iennichste bekende ûnderhâldsaksje is: rekke it net oan.

Ôfhinklikheid streamop: de ynterfacekast fan 'e generator fan 'e operator

Bedriuwsstatus: rint stabyl

De foto is it orizjinele byld op it plak dat troch de bydrager levere is; allinne de bestânsnamme is normalisearre, sûnder te snijen of oer te tekenjen.
