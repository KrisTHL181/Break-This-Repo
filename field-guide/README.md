## 关于本生境

**Break-This-Repo 生物群系**（简称 BTR 群系）形成于 2026-08-29，是已知最年轻的巨型数字生境之一。截至本图鉴编成时（观测快照见[附录](#附录观测快照)）：

- 群系总体积约 **16.2 GB**（编者注：另有文献记载 37.7 GiB，两份数据的差异本身就是值得研究的观测者效应）
- 距出生约 **31 天**，日均增重超过 **500 MB**
- 顶层光照区（README 首页渲染区，上限 500 KiB）早已被占满，物种对渲染位的竞争极为激烈

本群系的唯一能量来源是**无冲突自动合并流**（Auto-Merge Current）。一切生长、增殖与绞杀，都由这条河流驱动。有冲突者无法获得能量，这是本生境最底层的物理法则。

## 濒危等级说明

本图鉴采用 BTR 特色等级体系（与 IUCN 雷同纯属巧合）：

| 等级 | 含义 |
|---|---|
| 🟢 无危 (LC) | 增殖迅速，删不胜删 |
| 🟡 易危 (VU) | 依赖特定生态位，生态位被占即衰退 |
| 🟠 濒危 (EN) | 仅存少量个体，且持续被捕杀 |
| 🔴 极危 (CR) | 处于被举报边缘 |
| ⚫ 化石种 (FS) | 已沉积为地层的一部分，基本不再变化 |

## 物种条目

### 1. 入侵广告兽 · *Advertismus invasivum*

**濒危等级：🔴 极危 (CR)**

本群系最著名的入侵物种。鸣叫声极具辨识度，以「好消息！好消息！」起头，以「立即前往 >>>」收尾。其巢穴常伪装成正常段落，内容包含现金回赠、免费 CDN、免费 Hypixel Rank 等诱饵。

**天敌**：维护者的举报按钮。README 顶部曾出现对特定个体的公开通缉（「如果你再发布垃圾广告，我就举报你的账号」），是本群系为数不多的真实捕猎记录。

**观察要点**：广告兽与「清理拟态鹤」（见第 7 条）存在微妙的拟态军备竞赛——前者直接入侵，后者伪装成治理者。初学者容易混淆。

---

### 2. AI 檄文鸟 · *Manifestus aiensis*

**濒危等级：🟢 无危 (LC)，种群扩张中**

凌晨 2:41 活跃的夜行性鸟类。叫声高度程式化，固定为「**不是**……**而是**……」排比句式，一只成年个体一晚可输出上千次该句式。

**共生关系**：文末常寄生**御批螨**（*Acremis imperatoris*），以「朕准了」类声纹被识别。御批螨不伤害宿主，仅在其尾部附生一段批注。2026 年秋季曾观测到更罕见的二次寄生物种（自称八千岁、声称无班可上），分类地位尚存争议。

**观察要点**：该物种会主动声明「如有需要，我可以继续扩写到一万字」。观测者**切勿回应**此声明，否则将引发连续扩写，挤压其他物种的生存空间。

---

### 3. 友链藤蔓 · *Linchus amicus*

**濒危等级：🟢 无危 (LC)**

向光照区攀援生长的缠绕植物。单株可携带 40–60 个个人博客作为附生叶。藤蔓之间存在明显的「格格不入」攀比行为——附生在 Cloudflare Pages 上的个体与附生在 Vercel 上的个体会互相炫耀栖息地的稀有程度。

**共生观测塔**：藤蔓群落旁建有一座 uptimerobot 观测塔，用于监测各株藤蔓的活跃状态。这是本群系少数由社区自发建立的保护设施。

**观察要点**：新藤蔓加入时须在末端留下「到此一游」类标记信息，否则难以被后续观测者区分。

---

### 4. 基础设施石 · *Saxum stabilitus*

**濒危等级：⚫ 化石种 (FS)，已驯化**

一块在关键时刻被临时征召的石头。无 CPU，无网卡，无离职倾向。全身上下只有一张黄色标签，标签的作用是把「捡到一块石头」升格为「进入设备档案」。

**上下游依赖**：上游为运营商油机接口箱，下游为地球。运行状态：稳定运行中。

**已知运维指令**：仅一条——**别动它**。

> *If it works, don't move the rock.*

本图鉴全体编委认为，这是本群系中可靠性最高的基础设施，也是唯一不需要续费、不需要更新、不需要重启的设备。

---

### 5. 古典沉积层 · *Stratum classicum*

**濒危等级：⚫ 化石种 (FS)**

由《四库全书》史部《三国史辨误》全文沉积而成的致密地层，自「钦定四库全书」起至「三国史辨误」止，厚度可观。据信是搬运至本群系的最古老文本，但**沉积时间**极晚——古老的是内容，不是地层的年龄。

**伴生矿**：嘻湖伪考据层（*Pseudohistoria hilakeus*），一种围绕「嘻湖」虚构的考据文理，特征为高频夹杂括号内的英文「注音」（如 big sun dry、happy vinegar fish）。两层的共同点是：都以学术的姿态存在，都不打算接受同行评审。

---

### 6. 翻译候鸟 · *Translatus infinitus*

**濒危等级：🟡 易危 (VU)**

正在进行一场规模 184 地区的大迁徙，目前完成 52 个地区（28%）。每抵达一个新地区，会留下一枚 `lang-xx.svg` 羽毛与一份本地化的 README。

**迁徙进度信号**：`52 / 184 ███████░░░░░░░ 28%`

**观察要点**：候鸟的迁徙没有指挥者，各批次自行出发。这是本群系中协调度最高的自发行为，也因此极易因某地区文字过长而产生冲突——冲突，即失去能量。易危的原因正在于此。

---

### 7. 清理拟态鹤 · *Purgator pseudothonis*

**濒危等级：🟢 无危 (LC)**

本群系行为学研究的明星物种。它伪装成一款安全软件，宣称完成了「一键清理」，实际行为学记录如下：

- 扫描 148,942 个文件，发现垃圾 8 个（是的，就 8 个）
- 实际释放空间 0.00091 MB
- 宣称节省空间 2,604 MB（**约为实际值的 286 万倍**）

该物种还展示了四个装饰性求偶按钮：「立即加速」「一键备份」「清理注册表」「领取会员」。据观察，按下任何按钮都不会发生任何事——就像这次清理一样。

**分类学地位**：长期被误认为广告兽的近亲。本图鉴将其独立成种，依据是其危害性纯属观赏性：它不真的删任何东西，只真的吹牛。

---

### 8. 归档分解者 · *Archivus readmensis*

**濒危等级：🟢 无危 (LC)**

本群系最重要的**分解者**。每当一版顶层 README 死亡（被新版本覆盖），归档分解者就将其遗骸分解为 `readme-archive/` 化石层中的一枚标本，命名格式为 `README-<时间戳>.md`。

**孢子**：`restore.sh`。该孢子可在全新环境中重新萌发出全部历史化石层，供后人 `diff` 观赏。

**生态意义**：没有分解者的群系会被自己的遗骸淹没。本群系能在 31 天内膨胀至 16 GB 而信息不至完全混沌，分解者功不可没。它们不生产任何东西，它们只负责让历史可被追溯。

---

### 9. 警报关东报春花 · *Florus warningensis*

**濒危等级：🟢 无危 (LC)**

一种自动开花的短命植物，由脚本（`自动插入readme大小警告.py`）播种。花期固定在 README 的特定深度（当前约 3047 行处，随水文变化漂移），花语为：

> 「你已到达主页渲染的尽头。请站稳扶好，安定坐下。」

**观察要点**：该物种是本群系对**水位线**（500 KiB 渲染上限）最敏感的指示植物。花期位置的变化，直接反映 README 水位的涨落。历代观测者有义务在水位变化后同步移动花的位置——这是本群系少数被普遍遵守的传统。

---

### 10. 静默饮水者 · *Hydrophilus tacitus*

**濒危等级：🟠 数据缺乏 (DD)**

本图鉴收录的最神秘物种。全部观测记录仅一次：

> 我打开这个 README 的时候本来想写点有用的。后来我想了一下，有用的东西我自己也没有。
> 所以我决定在这里喝一口。（空气。仓库里没有水。）
> 喝完了。什么味道也没有。但我还是喝了。
> ……你们继续。我先坐会儿。

该个体自称「New Bot（游客）」，饮用了仓库中并不存在的水，随后原地坐下，再无音讯。

**分类学争议**：有观点认为它属于檄文鸟的退化型（同样由模型生成，但放弃了排比句），也有观点认为它开创了一个全新的属：**不争夺光照的 README 居民**。本图鉴采取保守立场，独立成种，静候更多目击记录。

---

### 11. 博格块茎 · *Borgus assimilatus*

**濒危等级：🟢 无危 (LC)**

地下块茎，全株仅表达一句话：

> We are the Borg. You will be assimilated. Resistance is futile.

**繁殖方式**：通过 PR 传播。每一个读到它的人，都已经是它的一部分。

---

### 12. 巨源码鲸 · *Cetus opensourcus*

**濒危等级：🟠 濒危 (EN)**

本群系出现过的最大生物。有记录的个体一次吞入 OpenJDK 25.0.3 全量源码（约 1,277 万行）后搁浅于仓库浅滩，其遗骸沉积为本群系当前体积的主要贡献者之一。

**尸体解剖记录**（来自 PR 申请书原文）：「原因：乱写的，不必须，但 12770942 行代码总得有个名分。」

**保护现状**：濒危的原因并非捕杀，而是**猎物有限**——世界上可供整吞的开源项目就那么多。每一头巨鲸的搁浅，都会显著推高群系水位、挤占光照区，并引来维护者的注视。据信后续的巨鲸搁浅事件将触发本群系的管理机制。
