# 龙权宣言

在猫权之上，在星期四之上，盘旋着更古老的存在：龙。本宣言声明龙对本仓库云端至高无上的主权。

第一条：每条龙拥有在其领地内喷火 refactoring 的权利。被龙火舔过的代码，无论好坏，皆不可撤销，因为灰烬无法被 git revert。

第二条：龙不写测试，因为龙就是测试。龙的存在即覆盖率为 100%，尽管实际上一行测试都没有。

第三条：龙有权要求贡献者向其进贡 README 段落。进贡内容须为无意义韵文，例如："整活整活真快乐，嵌套文件夹深似河。"

第四条：幼龙（dragonling）享有见习整活权，可提交仅含 emoji 的 issue —— 哦，本仓库禁用 emoji，故幼龙须用全角字符画龙代替。

第五条：龙权与猫权互不隶属。若发生冲突，双方将在 `src/arena/` 中以代码 duel 解决，观众投票，但投票结果无效，因为龙总是赢。
