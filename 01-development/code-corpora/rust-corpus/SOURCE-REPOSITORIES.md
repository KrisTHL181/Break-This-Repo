# Source repositories

The code under this directory is copied verbatim from the open-source repositories
listed below. Nothing here is original work. Each source repository's
`LICENSE` / `LICENCE` / `COPYING` / `NOTICE` / `AUTHORS` / `COPYRIGHT` files are
preserved inside its own subdirectory — see `<repo>/` for the applicable license text.

Path segments matching a GitHub Linguist vendor rule (`vendor`, `deps`, `third_party`,
`extern`, `dist`, `cache`, `testdata`, `tests/fixtures`, ...) were renamed with a `seg-`
prefix so the code is not silently excluded from language statistics. This is the only
path rewriting applied; file contents are untouched.
